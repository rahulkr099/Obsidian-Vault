# Lesson 1.1 — Initialize the Monorepo

Since you're using Linux Mint and are comfortable with the terminal, let's do this **terminal-first**.

Run:

```bash
node --version
npm --version
git --version
```

We'll also use `pnpm`.

Check:

```bash

```

```bash
corepack enable
```


# 5. Create `pnpm-workspace.yaml`

At the project root:

```bash
touch pnpm-workspace.yaml
```

It will define our workspace:

```yaml
packages:
  - "apps/*"
  - "packages/*"
```

This tells pnpm:

> Treat every directory inside `apps` and `packages` as a workspace package.

---

# 6. Root `package.json`

Our root package should eventually contain scripts such as:

```json
{
  "name": "ai-lms",
  "private": true,
  "scripts": {
    "dev": "pnpm --parallel --filter ./apps/* dev",
    "build": "pnpm --recursive build",
    "lint": "pnpm --recursive lint",
    "format": "pnpm --recursive format"
  }
}
```

Notice:

```json
"private": true
```

We don't want to accidentally publish the root workspace to npm.

# 🧠 Why We're Doing This First

You might wonder:

> "Why not just run `npm create vite` and start React?"

Because we're building a project that will eventually contain:

```text
Frontend
Backend
Database
Redis
Workers
AI
Shared types
Documentation
Infrastructure
```

Starting with the repository architecture prevents us from having to restructure everything later.

---

# ⚠️ One Important Rule

Don't create these yet:

```text
❌ microservices/
❌ ai-service/
❌ auth-service/
❌ course-service/
❌ notification-service/
```

Our backend is still:

```text
apps/api
```

with modules inside it.

For example:

```text
apps/api/src/modules/

auth/
courses/
lessons/
quizzes/
ai/
```

That's our **modular monolith**.
