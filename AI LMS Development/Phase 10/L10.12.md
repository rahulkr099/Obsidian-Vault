# 30. Logout

Logout should not simply mean:

```ts

```

Your authentication architecture already has a backend logout flow.

Use:

```text
Logout
 ↓

 ↓
Backend invalidates session/refresh token
 ↓
Clear frontend auth state
 ↓
Redirect /login
```

The exact implementation depends on the authentication architecture from the earlier phases.

This is important.

Don't create:

```tsx

   // giant component
}
else if (...)
```

everywhere.

For example:

```ts

  {
    label: "Dashboard",
    path: "/student/dashboard",
  },
  {
    label: "My Courses",
    path: "/student/courses",
  },
  {
    label: "Progress",
    path: "/student/progress",
  },
];
```

And:

```ts
const instructorNavigation = [
  {
    label: "Dashboard",
    path: "/instructor/dashboard",

  {
    label: "Courses",
```

# 37. Page vs Component

A useful rule:

### Page

Answers:

> "What screen am I looking at?"

Example:

```text
StudentDashboard.tsx
```

### Component

Answers:

> "What reusable part of that screen am I looking at?"

Example:

```text
ContinueLearningCard.tsx
```

### Hook

Answers:

> "How does this component get/manage data?"

Example:

```text
useStudentProgress.ts
```

### Service

Answers:

> "How do we communicate with the backend?"

Example:

```text
student.service.ts
```

This separation is one of the biggest lessons of Phase 10.

# 42. The Most Important Architecture Rule

At the end of Phase 10, think in **four layers**:

```text
┌───────────────────────────────┐
│            PAGES              │
│       What screen?            │
└───────────────┬───────────────┘
                ↓
┌───────────────────────────────┐
│         COMPONENTS            │
│        What UI?               │
└───────────────┬───────────────┘
                ↓
┌───────────────────────────────┐
│            HOOKS              │
│      What state/data?         │
└───────────────┬───────────────┘
                ↓
┌───────────────────────────────┐
│           SERVICES            │
│       What API call?          │
└───────────────┬───────────────┘
                ↓
             BACKEND
```

Don't mix these layers unnecessarily.

# 43. What We Should NOT Do

Avoid:

```text
❌ API calls directly inside every component
❌ Giant page components
❌ Duplicate student/instructor components
❌ Storing server data everywhere in local state
❌ Trusting frontend authorization
❌ Putting AI API keys in React
❌ Sending entire courses to the AI on every request
❌ Calculating official quiz scores in React
❌ Generating authoritative certificates in React
```
