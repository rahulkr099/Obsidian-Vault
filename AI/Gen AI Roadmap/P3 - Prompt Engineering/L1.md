---

## What is a Prompt?

A **prompt** is the input you provide to an AI model.

Examples:

```
Summarize this article.
```

```
Write a React login page.
```

```
Translate this into Hindi.
```

Everything you ask an LLM starts with a prompt.

---

## What is Prompt Engineering?

Prompt Engineering is the process of designing prompts that guide the AI to produce accurate, useful, and consistent responses.

Think of it as writing clear instructions for a very knowledgeable assistant.

The better your instructions, the better the results.

---

## Why Prompt Engineering Matters

Imagine asking two developers to build an API.

Developer A:

> Build an API.

Developer B:

> Build a REST API using Express.js with JWT authentication, MongoDB, input validation, proper error handling, and return JSON responses.

Who will produce a better result?

The second request is more specific.

LLMs work similarly.

## Characteristics of a Good Prompt

A good prompt is:

- Clear
- Specific
- Complete
- Context-rich
- Goal-oriented

Poor:

> Explain Docker.

Better:

> Explain Docker to a beginner using simple language with one real-world example and a comparison to virtual machines.

---

## Prompt Components

A strong prompt often includes:

1. Role
2. Task
3. Context
4. Constraints
5. Output format

Example:

```
Role:
You are a senior backend engineer.

Task:
Explain JWT authentication.

Context:
The audience is a college student learning Express.js.

Constraints:
Use simple English.
Limit to 300 words.

Output:
Markdown with headings.
```

---

## Common Prompting Mistakes

### Too Vague

```
Write code.
```

---

### No Context

```
Explain APIs.
```

To whom?

Beginner?

Senior engineer?

Manager?

---

### Missing Output Format

Without guidance, AI may return:

- Paragraphs
- Lists
- Tables
- Markdown
- JSON

Specify what you need.

---

## Prompt Engineering vs Programming

Programming:

```
if age >= 18:
    allow()
```

Prompt Engineering:

```
You are a travel assistant.

Recommend three budget-friendly destinations in India for college students.

Return the answer as a markdown table.
```

Both involve giving precise instructions, but prompts are written in natural language.

---

## Real Example

Poor Prompt:

```
Write a blog.
```

Better Prompt:

```
You are a technical writer.

Write a beginner-friendly blog explaining Docker.

Audience:
Backend developers.

Length:
800 words.

Include:
- What Docker is
- Why Docker is useful
- Real-world example
- Best practices

Use Markdown headings.
```

The second prompt is far more likely to produce the desired result.
