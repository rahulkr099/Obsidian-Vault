# Module 13 — Lesson 13.2: Common Domain Services ⭐⭐⭐⭐⭐

> **Goal:** Learn the most common Domain Services used in professional backend applications.

These services have **one focused responsibility** and are reused across different features.

---

# 1. SlugService

Responsibility:

```text
Generate Slugs

↓

Validate Slugs

↓

Ensure Uniqueness
```

Used by:

- Blog posts
    
- Categories
    
- Products
    

---

# 2. EmailService

Responsibility:

```text
Send Welcome Email

↓

Send Password Reset

↓

Send Verification Email
```

Every feature that needs email uses the same service.

---

# 3. NotificationService

Responsibility:

```text
Create Notification

↓

Send Push Notification

↓

Mark as Read
```

Used by:

- Blog
    
- Chat
    
- Orders
    
- LMS
    

---

# 4. StorageService

Responsibility:

```text
Upload File

↓

Delete File

↓

Get File URL
```

It hides whether you're using:

- Local storage
    
- AWS S3
    
- Cloudinary
    

The rest of your application doesn't need to know.

---

# 5. ImageService

Responsibility:

```text
Resize Image

↓

Compress Image

↓

Generate Thumbnail
```

All image-related logic stays in one place.

---

# Example

Instead of:

```text
PostService

↓

Resize Image

↓

Upload Image

↓

Generate Slug

↓

Send Notification
```

Use:

```text
PostService

↓

ImageService

↓

StorageService

↓

SlugService

↓

NotificationService
```

Now `PostService` only coordinates the workflow.

---

# Best Practices

✅ One domain service = One responsibility.

✅ Make domain services reusable.

✅ Don't duplicate the same logic in multiple feature services.

---

# Interview Question

**Q:** Why create a separate `EmailService` instead of sending emails directly from `UserService` or `PostService`?

**Good Answer:**

> Because sending emails is a separate responsibility that can be reused across multiple features. A dedicated `EmailService` keeps feature services focused and avoids duplicated email logic.

---

# Key Takeaways

- Domain Services encapsulate **shared business capabilities**.
    
- Examples include `EmailService`, `SlugService`, `NotificationService`, `StorageService`, and `ImageService`.
    
- Feature services coordinate these domain services rather than implementing their logic themselves.
