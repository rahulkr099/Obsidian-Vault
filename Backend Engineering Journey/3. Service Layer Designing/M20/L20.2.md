# Module 20 — Lesson 20.2: Batch Operations ⭐⭐⭐⭐⭐

> **Goal:** Learn how to reduce database calls by processing multiple records together.

A **batch operation** performs multiple actions in **one database request** instead of many separate requests.

---

# The Problem

Suppose you want to delete 100 notifications.

❌ Bad

```text
Loop

↓

Delete One

↓

Delete One

↓

Delete One

↓

...
```

100 database queries.

---

# Better

```text
Delete Many

↓

One Database Query
```

Much faster.

---

# Example 3 — Fetch Multiple Records

```text
Get All Users

One Query
```

---

# Real MongoDB Examples

Instead of:

```javascript
await User.create(user1);
await User.create(user2);
await User.create(user3);
```

Use:

```javascript
await User.insertMany([
  user1,
  user2,
  user3
]);
```

---

Instead of:

```javascript
await Notification.updateOne(...);
await Notification.updateOne(...);
```

Use:

```javascript
await Notification.updateMany(...);
```

---

# Best Practices

✅ Use `insertMany()` for bulk inserts.

✅ Use `updateMany()` for bulk updates.

✅ Use `deleteMany()` for bulk deletes.

✅ Avoid database queries inside loops.

---

# Interview Question

**Q:** What is a batch operation, and why is it useful?

**Good Answer:**

> A batch operation performs multiple database changes in a single request instead of many individual requests. It reduces network overhead, improves performance, and lowers database load.

---

# Key Takeaways

- Batch operations reduce database calls.
    
- Avoid loops that execute queries repeatedly.
    
- Use bulk database operations whenever appropriate.
    
- Fewer queries generally lead to better performance.
