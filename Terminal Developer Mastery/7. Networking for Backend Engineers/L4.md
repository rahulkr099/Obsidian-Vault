# What is a Subnet?

A **subnet (subnetwork)** is a smaller network created from a larger network.

Instead of putting every device into one huge network, we divide it into smaller groups.

Imagine a company:

```text
Company Network

├── HR
├── Finance
├── Engineering
└── Sales
```

Each department can have its own subnet.

---

# Why Do We Need Subnets?

Imagine one network with **10,000 devices**.

Problems:

- Too much broadcast traffic
    
- Harder to manage
    
- Poor performance
    
- Lower security
    

Instead:

```text
Company

├── HR
│   └── 192.168.10.0/24
│
├── Finance
│   └── 192.168.20.0/24
│
├── Engineering
│   └── 192.168.30.0/24
│
└── Sales
    └── 192.168.40.0/24
```

Now each department has its own network.

---

# Understanding CIDR Notation

CIDR stands for:

> **Classless Inter-Domain Routing**

Example:

```text
192.168.1.0/24
```

The `/24` is called the **prefix length**.

It tells us:

> How many bits identify the **network**.

---

# IPv4 Refresher

IPv4 has:

```text
32 bits
```

Example:

```text
192.168.1.20
```

In binary:

```text
11000000
10101000
00000001
00010100
```

Four octets:

```text
8 + 8 + 8 + 8 = 32 bits
```

---

# What Does `/24` Mean?

```text
192.168.1.20/24
```

Means:

```text
Network bits = 24

Host bits = 8
```

Visualization:

```text
11111111.11111111.11111111.00000000
```

The first 24 bits identify the network.

The last 8 bits identify individual devices (hosts).

---

# Most Common Prefixes

## /8

```text

```

Network:

```text
10
```

Host part:

```text
0.0.0
```

Huge network.

---

## /16

```text
172.16.0.0/16
```

Network:

```text
172.16
```

Host:

```text
0.0
```

---

## /24

```text
192.168.1.0/24
```

Network:

```text
192.168.1
```

```text
0
```

This is the most common subnet in homes and small offices.

# Network ID

Every subnet has one **Network ID**.

Example:

```text
192.168.1.0/24
```

Network ID:

```text
192.168.1.0
```

It identifies the subnet itself and cannot be assigned to a device.

---

# Broadcast Address

Every subnet also has one **Broadcast Address**.

Example:

```text
192.168.1.255
```

If data is sent there:

```text
Laptop

↓

192.168.1.255

↓

Every device in the subnet receives it.
```

This address cannot be assigned to a host.

---

# Usable Hosts

For:

```text
192.168.1.0/24
```

Reserved:

```text
192.168.1.0
```

Network ID

and

```text
192.168.1.255
```

Broadcast

Everything in between is usable:

```text
192.168.1.1

↓

192.168.1.254
```

That's **254 usable IP addresses**.

---

# Another Example

Network:

```text
192.168.10.0/24
```

|Address|Purpose|
|---|---|
|192.168.10.0|Network ID|
|192.168.10.1|First usable host|
|192.168.10.2|Host|
|...|...|
|192.168.10.254|Last usable host|
|192.168.10.255|Broadcast|

---

# Host Portion

Example:

```text
192.168.1.45/24
```

Network:

```text
192.168.1
```

Host:

```text
45
```

Only the host portion changes inside a subnet.

# Same Network?

Suppose:

Computer A:

```text
192.168.1.20/24
```

Computer B:

```text
192.168.1.80/24
```

Network:

```text
192.168.1
```

Both are in the **same subnet** and can communicate directly (assuming firewall rules allow it).

---

Now:

Computer A:

```text
192.168.1.20
```

Computer B:

```text
192.168.2.30
```

Different network:

```text
192.168.1

vs

192.168.2
```

They need a **router** to communicate.

# CIDR Quick Reference

|CIDR|Subnet Mask|Usable Hosts|
|---|---|--:|
|/8|255.0.0.0|16,777,214|
|/16|255.255.0.0|65,534|
|/24|255.255.255.0|254|
|/25|255.255.255.128|126|
|/26|255.255.255.192|62|
|/27|255.255.255.224|30|
|/28|255.255.255.240|14|
|/29|255.255.255.248|6|
|/30|255.255.255.252|2|

> **Interview tip:** You don't need to memorize every row. The most commonly used prefixes are `/24`, `/16`, `/8`, and you'll also see `/32` (single host) and `/0` (default route) in routing tables.

# Subnet Mask

A subnet mask is another way to express the prefix length.

Examples:

|CIDR|Subnet Mask|
|---|---|
|/8|255.0.0.0|
|/16|255.255.0.0|
|/24|255.255.255.0|

So:

```text
192.168.1.20/24
```

is equivalent to:

```text
192.168.1.20
Mask:
255.255.255.0
```

Modern Linux tools typically display the CIDR form.

# Why Backend Engineers Care

Cloud providers use subnets everywhere.

AWS example:

```text
VPC

├── Public Subnet
│     10.0.1.0/24
│
└── Private Subnet
      10.0.2.0/24
```

Docker also creates bridge networks such as:

```text
172.17.0.0/16
```

Kubernetes clusters also rely heavily on subnetting for pod and service networking.

# Linux Commands

## View IP addresses

```bash
ip addr
```

Example:

```text
inet 192.168.1.20/24
```

Notice the `/24`.

---

## View routes

```bash
ip route
```

Example:

```text
default via 192.168.1.1 dev wlp2s0

192.168.1.0/24 dev wlp2s0 proto kernel
```

The second line tells Linux that `192.168.1.0/24` is directly connected.

---

## Show only IPv4 addresses

```bash
hostname -I
```

# Real Backend Example

Suppose your Express server runs on:

```javascript
app.listen(5000);
```

Your laptop:

```text
192.168.1.20
```

Another laptop:

```text
192.168.1.35
```

If both are on the same `/24` network, the second laptop can access your API (if your application is listening on the appropriate interface and firewall settings permit it):

```text
http://192.168.1.20:5000
```

If the other laptop is on a different subnet, a router must forward the traffic between the two networks.

# Common Interview Questions

### 1. What is subnetting?

Subnetting is the process of dividing a larger network into smaller, more manageable networks called subnets.

---

### 2. What does `/24` mean?

It means the first 24 bits identify the network, leaving the remaining 8 bits for host addresses.

---

### 3. What is the Network ID?

The Network ID identifies the subnet itself and is the first address in the subnet. It cannot be assigned to a host.

---

### 4. What is the Broadcast Address?

The Broadcast Address is the last address in the subnet and is used to send packets to all hosts within that subnet.

---

### 5. How many usable addresses are in a `/24` network?

A `/24` subnet contains 256 total addresses. Two are reserved (Network ID and Broadcast Address), leaving **254 usable host addresses**.

---

# Key Takeaways

- A **subnet** is a smaller network created from a larger network.
    
- **CIDR notation** (`/24`, `/16`, `/8`) specifies how many bits represent the network.
    
- The **Network ID** is the first address in the subnet.
    
- The **Broadcast Address** is the last address in the subnet.
    
- Hosts in the same subnet can communicate directly; hosts in different subnets require a router.
    
- Subnetting is fundamental in cloud platforms, Docker, Kubernetes, and enterprise networking.
