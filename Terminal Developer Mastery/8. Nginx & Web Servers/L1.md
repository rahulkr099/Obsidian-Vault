# What is a Web Server?

A **web server** is software that listens for HTTP/HTTPS requests and returns web content.

It acts as the middleman between users and applications.

Example:

```
Browser
    |
HTTP Request
    |
Web Server
    |
HTML Page
    |
Browser
```

Example request:

```
GET /
```

Example response:

```
HTTP/1.1 200 OK

<html>
Welcome
</html>
```

The browser never directly talks to your application files.

Everything goes through a web server.

---

# Real Example

When you open

```
https://github.com
```

The browser sends

```
GET /
```

GitHub's Nginx servers receive it.

Then they decide:

- serve HTML
    
- call backend APIs
    
- load images
    
- compress responses
    
- cache files
    
- secure traffic
    

All before the response reaches you.

# Why Do We Need a Web Server?

Without one:

```

      |
Application
```

Problems:

- No static file optimization
    
- No HTTPS
    
- No caching
    
- No compression
    
- No load balancing
    
- No logging
    
- Poor performance
    

With a web server:

```
Browser
     |
  Nginx
     |
Backend App
```

Now you gain:

- Faster responses
    
- Better security
    
- SSL/TLS
    
- Load balancing
    
- Caching
    
- Logging
    
- Compression

# Static Content

Static content never changes unless someone edits the file.

Examples:

```
index.html

style.css

logo.png

resume.pdf

script.js
```

Request

```

```

Response


No backend.

No computation.

Just return the file.

Very fast.

# Dynamic Content

Dynamic content is generated at request time.

Example:

```

```

The server asks:

```

↓

Find User

↓

↓

Return Response
```

Different users receive different data.

Examples:

- Gmail inbox
    
- Instagram feed
    
- YouTube recommendations
    
- Shopping cart
    
- Dashboard
    
- Banking apps

# Static vs Dynamic

|Static|Dynamic|
|---|---|
|HTML file|Generated by backend|

|No database|Usually needs database|
|Same for everyone|Different for each user|

# Interview Questions

### 1. What is a web server?

A web server is software that listens for HTTP/HTTPS requests and returns web content such as HTML, images, or data, or forwards requests to backend applications.

---

### 2. What is the difference between static and dynamic content?

Static content is stored as files and served directly. Dynamic content is generated by backend code, often using databases or other services.

---

### 3. Why is Nginx popular?

Because it is event-driven, highly scalable, memory-efficient, supports reverse proxying, load balancing, HTTPS, caching, compression, and can handle a very large number of concurrent connections.

---

### 4. Does Nginx replace Node.js?

No. Nginx and Node.js have different roles. Nginx handles incoming web traffic and web server tasks, while Node.js runs your application logic.

---

### 5. Can Nginx serve HTML without Node.js?

Yes. Nginx can directly serve static files like HTML, CSS, JavaScript, images, and PDFs without needing a backend application.
