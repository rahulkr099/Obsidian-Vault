# 1. What is a Request Body?

An HTTP request has **three main parts**:

```
Request Line
Headers
Body (optional)
```

Example:

```
POST /users HTTP/1.1
Host: api.example.com
Content-Type: application/json

{
  "name": "Rahul"
}
```

The JSON at the bottom is the **request body**.

It contains the actual data you want to send.

---

# 2. Real-Life Analogy

Imagine you're filling out a job application.

The envelope contains:

```
Recipient Address
```

Similar to:

```
URL
```

The label says:

```
Urgent
```

Similar to:

```
Headers
```

The application form inside contains:

```
Name
Phone
Skills
Experience
```

That is like the **request body**.

The body carries the information that matters.

---

# 3. URL vs Headers vs Body

Suppose you're creating a new user.

### URL

```
POST /users
```

Tells the server **where** to send the request.

---

### Headers

```
Content-Type: application/json
```

Tell the server **how** to interpret the request.

---

### Body

```json
{
  "name": "Rahul",
  "age": 21
}
```

Contains the actual data.

---

# 4. Which Methods Usually Have a Body?

|Method|Request Body?|
|---|---|
|GET|❌ Usually No|
|POST|✅ Yes|
|PUT|✅ Yes|
|PATCH|✅ Yes|
|DELETE|⚠️ Sometimes (API-dependent)|
|HEAD|❌ No|
|OPTIONS|❌ Usually No|

Most REST APIs expect bodies with **POST**, **PUT**, and **PATCH**.

---

# 5. Your First Request Body

Run:

```bash
curl \
-X POST \
-H "Content-Type: application/json" \
-d '{"name":"Rahul"}' \
<https://httpbin.org/post>
```

You'll receive JSON that includes:

```json
{
  "json": {
    "name": "Rahul"
  }
}
```

`httpbin` echoes back the data it received, making it a great learning tool.

---

# 6. How Express Receives It

Express:

```jsx
import express from "express";

const app = express();

app.use(express.json());

app.post("/users", (req, res) => {
  console.log(req.body);

  res.json(req.body);
});
```

If you run:

```bash
curl \
-X POST \
-H "Content-Type: application/json" \
-d '{"name":"Rahul"}' \
<http://localhost:3000/users>
```

The server logs:

```jsx
{
  name: "Rahul"
}
```

The data is available in:

```jsx
req.body
```

---

# 7. Why `express.json()` Matters

Without:

```jsx
app.use(express.json());
```

`req.body` will usually be:

```jsx
undefined
```

because Express won't automatically parse JSON.

Always enable the appropriate middleware before your routes.

---

# 8. Common Mistakes

### ❌ Forgetting `Content-Type`

```bash
curl \
-d '{"name":"Rahul"}'
```

Some servers may not recognize the body as JSON.

---

### ✅ Correct

```bash
curl \
-H "Content-Type: application/json" \
-d '{"name":"Rahul"}'
```

---

### ❌ Invalid JSON

```bash
-d '{name:"Rahul"}'
```

Property names in JSON must be quoted.

---

### ✅ Valid JSON

```bash
-d '{"name":"Rahul"}'
```
