# Step 2 — Helper Functions

## `scripts/helpers.sh`

```bash
#!/usr/bin/env bash

GREEN="\033[0;32m"
RED="\033[0;31m"
BLUE="\033[0;34m"
RESET="\033[0m"

success() {
    echo -e "${GREEN}$1${RESET}"
}

error() {
    echo -e "${RED}$1${RESET}"
}

info() {
    echo -e "${BLUE}$1${RESET}"
}
```

Usage:

```bash
success "Login successful"
```

---

# Step 3 — Authentication

## `scripts/auth.sh`

```bash
#!/usr/bin/env bash

source scripts/config.sh

TOKEN=$(
curl -s \
-H "Content-Type: application/json" \
-d @payloads/login.json \
"$API/api/auth/login" |
jq -r '.accessToken'
)

echo "$TOKEN"
```

---

# Step 4 — Create Todo

```bash
#!/usr/bin/env bash

TOKEN=$(bash scripts/auth.sh)

curl \
-H "Authorization: Bearer $TOKEN" \
-H "Content-Type: application/json" \
-d @payloads/todo.json \
"$API/api/todos"
```

---

# Step 5 — Capture Todo ID

```bash
TODO_ID=$(
curl -s \
-H "Authorization: Bearer $TOKEN" \
-H "Content-Type: application/json" \
-d @payloads/todo.json \
"$API/api/todos" |
jq -r '._id'
)
```

Now:

```bash
echo "$TODO_ID"
```

---

# Step 6 — Update Todo

```bash
curl \
-X PATCH \
-H "Authorization: Bearer $TOKEN" \
-H "Content-Type: application/json" \
-d @payloads/update.json \
"$API/api/todos/$TODO_ID"
```

---

# Step 7 — Delete Todo

```bash
curl \
-X DELETE \
-H "Authorization: Bearer $TOKEN" \
"$API/api/todos/$TODO_ID"
```

---

# Step 8 — Logging

Instead of losing output:

```bash
curl ... > logs/login.log
```

or

```bash
curl ... | tee logs/login.log
```

Now you can inspect previous responses.

---

# Step 9 — Check Status Codes

```bash
STATUS=$(
curl \
-s \
-o /dev/null \
-w "%{http_code}" \
"$API/api/todos"
)

echo "$STATUS"
```

Example:

```
200
```

---

# Step 10 — Error Handling

```bash
if [ "$STATUS" -eq 200 ]; then
    success "Request succeeded"
else
    error "Request failed"
fi
```

# Step 12 — Reusable Function

Instead of repeating:

```bash
curl \
-H "Authorization: Bearer $TOKEN"
```

Create:

```bash
api() {

curl \
-H "Authorization: Bearer $TOKEN" \
"$@"

}
```

Now:

```bash
api <http://localhost:3000/api/todos>
```

---

# Step 13 — Create a Generic POST Function

```bash
post() {

curl \
-H "Authorization: Bearer $TOKEN" \
-H "Content-Type: application/json" \
-d @"$2" \
"$API/$1"

}
```

Example:

```bash
post api/todos payloads/todo.json
```

This reduces repetitive typing.
