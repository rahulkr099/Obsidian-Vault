# Step 1 — Register a User

Create:

## payloads/register.json

```json
{
  "name": "Rahul",
  "email": "rahul@example.com",
  "password": "secret123"
}
```

Send:

```bash
curl \
-H "Content-Type: application/json" \
-d @payloads/register.json \
<http://localhost:3000/api/auth/register> | jq
```

Expected response:

```json
{
  "success": true,
  "message": "User registered successfully"
}
```

---

# Step 2 — Login

Create:

## payloads/login.json

```json
{
  "email": "rahul@example.com",
  "password": "secret123"
}
```

Run:

```bash
curl \
-H "Content-Type: application/json" \
-d @payloads/login.json \
<http://localhost:3000/api/auth/login> | jq
```

Example response:

```json
{
  "accessToken": "eyJhbGciOi...",
  "refreshToken": "eyJhbGciOi..."
}
```

# Step 3 — Store the Access Token

Instead of copying and pasting the JWT every time, capture it in a shell variable.

```bash
TOKEN=$(
curl -s \
-H "Content-Type: application/json" \
-d @payloads/login.json \
<http://localhost:3000/api/auth/login> \
| jq -r '.accessToken'
)
```

Verify:

```bash
echo "$TOKEN"
```

Now the token can be reused.

# Step 6 — Save the Todo ID

Instead of copying the ID manually:

```bash
TODO_ID=$(
curl -s \
-H "Authorization: Bearer $TOKEN" \
-H "Content-Type: application/json" \
-d @payloads/todo.json \
<http://localhost:3000/api/todos> \
| jq -r '._id'
)
```

Verify:

```bash
echo "$TODO_ID"
```

# Automating with Bash

## [login.sh](http://login.sh)

```bash
#!/usr/bin/env bash

TOKEN=$(
curl -s \
-H "Content-Type: application/json" \
-d @payloads/login.json \
<http://localhost:3000/api/auth/login> \
| jq -r '.accessToken'
)

echo "Token acquired."
echo "$TOKEN"
```

Run:

```bash
chmod +x scripts/login.sh

./scripts/login.sh
```

# Environment Variables

Avoid hardcoding URLs.

Instead:

```bash
API=http://localhost:3000
```

Now:

```bash
curl \
-H "Authorization: Bearer $TOKEN" \
$API/api/todos
```

Changing environments becomes simple:

```bash
API=http://localhost:5000
```

or

```bash
API=https://api.example.com
```

No other commands need to change.

---

# Using `.env`

You can keep reusable values in a file.

```bash
API=http://localhost:3000
EMAIL=rahul@example.com
```

Load them:

```bash
source .env
```

Then:

```bash
echo "$API"
```

> **Note:** In production projects, avoid storing secrets like passwords or JWTs in plaintext `.env` files that are committed to Git. Add `.env` to `.gitignore`.

# Using `jq` Effectively

Only show titles:

```bash
curl \
-H "Authorization: Bearer $TOKEN" \
<http://localhost:3000/api/todos> \
| jq '.[].title'
```

Count todos:

```bash
curl \
-H "Authorization: Bearer $TOKEN" \
<http://localhost:3000/api/todos> \
| jq 'length'
```

Filter completed todos:

```bash
curl \
-H "Authorization: Bearer $TOKEN" \
<http://localhost:3000/api/todos> \
| jq '.[] | select(.completed == true)'
```
