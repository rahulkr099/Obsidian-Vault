# What is `sed`?

`sed` stands for **Stream Editor**.

It reads text line by line, applies commands, and prints the result.

It **does not modify the original file** unless you explicitly tell it to.

Basic syntax:

```bash
sed 'command' filename
```

or

```bash
command | sed 'command'
```

---

# Viewing a File

Suppose `file.txt` contains:

```
Hello
Linux
World
```

Display it:

```bash
sed '' file.txt
```

Output:

```
Hello
Linux
World
```

---

# Replace Text

The most common `sed` command:

```bash
sed 's/old/new/' file.txt
```

Example:

```
Hello Linux
```

Command:

```bash
sed 's/Linux/Ubuntu/' file.txt
```

Output:

```
Hello Ubuntu
```

Only the **first** match on each line is replaced.

---

# Replace Every Match

Use the **g** (global) flag.

File:

```
Linux Linux Linux
```

Command:

```bash
sed 's/Linux/Ubuntu/g'
```

Output:

```
Ubuntu Ubuntu Ubuntu
```

---

# Replace Ignoring Case

GNU `sed` supports the `I` flag:

```bash
sed 's/linux/Ubuntu/I'
```

Example:

```
linux
Linux
LINUX
```

becomes

```
Ubuntu
Ubuntu
Ubuntu
```

---

# Delete Lines

Delete line 3:

```bash
sed '3d' file.txt
```

Delete lines 3–6:

```bash
sed '3,6d' file.txt
```

Delete blank lines:

```bash
sed '/^$/d' file.txt
```

---

# Print Only Specific Lines

Normally `sed` prints every line.

Suppress automatic output:

```bash
sed -n '5p' file.txt
```

Print line 5 only.

Print lines 10–20:

```bash
sed -n '10,20p' file.txt
```

---

# Remove HTML Tags

Suppose HTML:

```html
<h1>Linux News</h1>
```

Remove the tags:

```bash
echo "<h1>Linux News</h1>" | sed 's/<[^>]*>//g'
```

Output:

```
Linux News
```

Explanation:

```
<[^>]*>

<      Start tag

[^>]  Anything except >

*      Zero or more characters

>      End tag
```

This is one of the most common `sed` patterns in simple scraping tasks.

---

# Clean HTML from curl

```bash
curl -s <https://example.com> |
grep "<h1>" |
sed 's/<[^>]*>//g'
```

Output:

```
Example Domain
```

Workflow:

```
Website
    ↓
curl
    ↓
HTML
    ↓
grep
    ↓
<h1>Example Domain</h1>
    ↓
sed
    ↓
Example Domain
```

---

# Replace Characters

Example:

```
Linux-Server
```

Replace `-` with space:

```bash
sed 's/-/ /'
```

Output:

```
Linux Server
```

---

# Remove Extra Spaces

Input:

```
Hello     Linux
```

Command:

```bash
sed 's/  */ /g'
```

Output:

```
Hello Linux
```

This replaces multiple consecutive spaces with a single space.

---

# Remove Leading Spaces

```bash
sed 's/^ *//'
```

Example:

```
        Ubuntu
```

becomes

```
Ubuntu
```

---

# Remove Trailing Spaces

```bash
sed 's/ *$//'
```

Useful when cleaning downloaded text.

---

# Add Text

Add a prefix:

```bash
sed 's/^/-> /'
```

Example:

```
Ubuntu
```

becomes

```
-> Ubuntu
```

---

# Add Text at the End

```bash
sed 's/$/ ✓/'
```

Example:

```
Ubuntu
```

becomes

```
Ubuntu ✓
```

---

# Print Matching Lines Only

```bash
sed -n '/Ubuntu/p'
```

Equivalent to a simple `grep` search, but useful inside larger `sed` scripts.

# Process HTML Titles

Example HTML:

```html
<title>Linux News</title>
```

Extract only the title:

```bash
echo "<title>Linux News</title>" |
sed 's/<[^>]*>//g'
```

Output:

```
Linux News
```

---

# Extract Paragraph Text

HTML:

```html
<p>Learning curl is fun.</p>
```

Command:

```bash
echo "<p>Learning curl is fun.</p>" |
sed 's/<[^>]*>//g'
```

Output:

```

```

# Combine `curl`, `grep`, and `sed`

Extract a page title:

```bash
curl -s <https://example.com> |
grep "<title>" |
sed 's/<[^>]*>//g'
```

Output:

```
Example Domain
```

---

# Save Clean Data

```bash
curl -s <https://example.com> |
grep "<title>" |
sed 's/<[^>]*>//g' > title.txt
```

View it:

```bash
cat title.txt
```

---

# In-Place Editing

To modify a file directly:

```bash
sed -i 's/Linux/Ubuntu/g' file.txt
```

⚠️ **Be careful.** The original file is changed.

A safer approach is to create a backup:

```bash
sed -i.bak 's/Linux/Ubuntu/g' file.txt
```

This edits `file.txt` and keeps the original as `file.txt.bak`.

# Common Mistakes

❌ Forgetting the `g` flag when replacing multiple matches.

```bash
sed 's/Linux/Ubuntu/'
```

Only the first occurrence on each line is replaced.

Use:

```bash
sed 's/Linux/Ubuntu/g'
```

---

❌ Using `sed -i` without a backup.

Always consider:

```bash
sed -i.bak 's/old/new/g' file.txt
```

---

❌ Trying to parse complex HTML using only `sed`.

`sed` is excellent for simple transformations, but for deeply nested or JavaScript-generated HTML, dedicated parsers are more reliable.

# Real-World Example

Suppose a website returns:

```html
<h2>Today's Weather</h2>
<p>Temperature: 31°C</p>
```

You can quickly clean it:

```bash
curl -s <https://example.com> |
grep -E "<h2>|<p>" |
sed 's/<[^>]*>//g'
```

Output:

```
Today's Weather
Temperature: 31°C
```

This is a common pattern in shell automation scripts.

---

# Key Takeaways

- `sed` edits text streams efficiently.
- The `s/old/new/` command performs substitutions.
- The `g` flag replaces all matches on a line.
- `n` prints selected lines.
- `i` edits files in place.
- `sed` works well with `curl` and `grep` for cleaning HTML.
- Simple HTML tags can be removed with `sed 's/<[^>]*>//g'`.

### 💡 Backend Engineer Tip

A very common shell pipeline you'll encounter in production is:

```bash
curl -s <https://example.com> \
| grep "<title>" \
| sed 's/<[^>]*>//g'
```

This demonstrates a classic Unix philosophy:

- `curl` → fetch the data
- `grep` → find the relevant lines
- `sed` → clean or transform the output
