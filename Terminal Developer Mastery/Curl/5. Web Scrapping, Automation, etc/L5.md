# What is `awk`?

`awk` is a programming language designed for processing structured text.

It treats each line as a **record** and splits it into **fields**.

Example file:

```
Rahul 21 Student
Amit 23 Developer
Priya 20 Designer
```

Think of it as:

|$1|$2|$3|
|---|---|---|
|Rahul|21|Student|
|Amit|23|Developer|
|Priya|20|Designer|

- `$1` → First field
- `$2` → Second field
- `$3` → Third field
- `$0` → Entire line

---

# Basic Syntax

```bash
awk '{print $1}' file.txt
```

Example:

```
Rahul 21 Student
Amit 23 Developer
```

Output:

```
Rahul
Amit
```

---

# Print Multiple Fields

```bash
awk '{print $1, $3}' file.txt
```

Output:

```
Rahul Student
Amit Developer
```

---

# Print Entire Line

```bash
awk '{print $0}' file.txt
```

Output:

```
Rahul 21 Student
Amit 23 Developer
```

---

# Number of Fields

`NF` means **Number of Fields**.

Example:

```
Linux Mint Cinnamon
```

Command:

```bash
echo "Linux Mint Cinnamon" | awk '{print NF}'
```

Output:

```
3
```

---

# Last Field

Use:

```bash
awk '{print $NF}'
```

Example:

```
Rahul 21 Student
```

Output:

```
Student
```

---

# First and Last Together

```bash
awk '{print $1, $NF}'
```

Output:

```
Rahul Student
```

---

# Filtering Records

Suppose:

```
Rahul 21
Amit 18
Priya 25
```

Print only people older than 20:

```bash
awk '$2 > 20'
```

Output:

```
Rahul 21
Priya 25
```

---

# Conditional Printing

```bash
awk '$2 > 20 {print $1}'
```

Output:

```
Rahul
Priya
```

---

# Using Different Separators

By default, `awk` splits on whitespace.

For CSV files:

```
Rahul,21,Student
Amit,23,Developer
```

Use:

```bash
awk -F',' '{print $1}'
```

Output:

```
Rahul
Amit
```

---

# Working with `/etc/passwd`

Linux uses `:` as a separator.

Example:

```
root:x:0:0:root:/root:/bin/bash
```

Extract usernames:

```bash
awk -F':' '{print $1}' /etc/passwd
```

Extract login shells:

```bash
awk -F':' '{print $7}' /etc/passwd
```

---

# Built-in Variables

|Variable|Meaning|
|---|---|
|`$0`|Entire line|
|`$1`|First field|
|`$2`|Second field|
|`NF`|Number of fields|
|`NR`|Current record number|
|`FNR`|Record number within current file|

Example:

```bash
awk '{print NR, $0}' file.txt
```

Output:

```
1 Rahul 21
2 Amit 18
3 Priya 25
```

# Arithmetic

Example:

```
Laptop 800
Mouse 20
Keyboard 50
```

Calculate tax:

```bash
awk '{print $1, $2*1.18}'
```

Output:

```
Laptop 944
Mouse 23.6
Keyboard 59
```

---

# Summing Values

Example:

```
10
20
30
40
```

Command:

```bash
awk '{sum += $1} END {print sum}'
```

Output:

```
100
```

---

# Average

```bash
awk '{sum += $1} END {print sum/NR}'
```

Output:

```
25
```

---

# Finding Maximum

```
12
55
8
91
45
```

Command:

```bash
awk 'max<$1 {max=$1} END {print max}'
```

Output:

```
91
```

---

# Finding Minimum

```bash
awk 'NR==1 || $1<min {min=$1} END {print min}'
```

---

# Formatting Output

Example:

```bash
awk '{printf "%-10s %5d\n",$1,$2}'
```

Output:

```
Rahul         21
Amit          18
Priya         25
```

This produces neatly aligned columns.

# Processing `curl` Output

Suppose:

```bash
curl -s <https://example.com>
```

returns:

```html
<title>Example Domain</title>
```

Pipeline:

```bash
curl -s <https://example.com> \
| grep "<title>" \
| sed 's/<[^>]*>//g' \
| awk '{print $1,$2}'
```

Output:

```
Example Domain
```

---

# Extracting Log Data

Example log:

```

INFO Request complete
ERROR Timeout
```

Extract only errors:

```bash

```

Output:

```
ERROR Database down

```

# Selecting Columns

Example:

```
Name Age Salary
Rahul 21 45000
Amit 25 60000
```

Print salary:

```bash
awk '{print $3}'
```

Output:

```
Salary
45000
60000
```

Skip the header:

```bash
awk 'NR>1 {print $3}'
```

Output:

```
45000
60000
```

# Complete Unix Pipeline

```
Website
     ↓
curl
     ↓
HTML
     ↓
grep
     ↓
Relevant line
     ↓
sed
     ↓
Clean text
     ↓
awk
     ↓
Formatted report
```

Example:

```bash
curl -s <https://example.com> \
| grep "<title>" \
| sed 's/<[^>]*>//g' \
| awk '{print "Website:",$0}'
```

Output:

```
Website: Example Domain
```

# Common Mistakes

❌ Forgetting that field numbers start at **1**, not **0**.

Incorrect:

```bash
awk '{print $0}'
```

Thinking it prints the first field.

Actually:

- `$0` → Entire line
- `$1` → First field

---

❌ Using the wrong separator.

CSV:

```
Rahul,21,Student
```

Incorrect:

```bash
awk '{print $1}'
```

Correct:

```bash
awk -F',' '{print $1}'
```

---

❌ Expecting `awk` to parse HTML.

`awk` works best with **structured text**. For HTML, first narrow the content with `grep` and clean it with `sed`, then use `awk` for formatting or calculations.

# Real-World Backend Example

Suppose you're monitoring API response times:

```
GET /users 120
GET /posts 95
GET /login 250
GET /health 40
```

Show only slow requests:

```bash
awk '$3 > 100'
```

Output:

```
GET /users 120
GET /login 250
```

This kind of filtering is commonly used in server monitoring and log analysis.

---

# Best Practices

- Use `F` whenever your data isn't separated by spaces.
- Prefer `printf` over `print` for reports that need aligned columns.
- Let `awk` handle calculations instead of writing loops in shell scripts.
- Combine `awk` with `grep` and `sed`—each tool has a specific strength.

---

# Key Takeaways

- `awk` processes structured text field by field.
- `$1`, `$2`, ..., `$NF` refer to fields.
- `NR` tracks line numbers.
- `F` changes the field separator.
- `awk` can filter, calculate, summarize, and format data.
- It's a core tool for Linux automation, DevOps, backend engineering, and log analysis.

## 💡 Backend Engineer Tip

You'll frequently see pipelines like this in production:

```bash
curl -s <https://example.com/api/logs> \
| jq '.[] | [.endpoint, .response_time] | @tsv' \
| awk '$2 > 200 {printf "%-20s %4d ms\n", $1, $2}'
```

Notice the workflow:

- `curl` → Fetch data
- `jq` → Convert JSON into tabular text
- `awk` → Filter, calculate, and format

As a backend engineer, becoming comfortable with `awk` will make debugging logs, analyzing metrics, and writing automation scripts much faster.
