# Step 1: Check if Git is Already Installed

Open your terminal and run:

```bash
git --version
```

Example output:

```text
git version 2.50.1
```

If you see a version number, Git is already installed.

If you see:

```text
git: command not found
```

then you need to install Git.

---

# Installing Git on Linux

## Ubuntu / Debian / Linux Mint

Update package lists:

```bash
sudo apt update
```

Install Git:

```bash
sudo apt install git
```

Verify:

```bash
git --version
```

---

## Fedora

```bash
sudo dnf install git
```

---

## Arch Linux

```bash
sudo pacman -S git
```

---

## openSUSE

```bash
sudo zypper install git
```

# Where is Git Installed?

Find the Git executable.

Linux/macOS:

```bash
which git
```

Example:

```text
/usr/bin/git
```

Windows (Git Bash):

```bash
which git
```

Example:

```text
/mingw64/bin/git
```

Another option (Linux):

```bash
command -v git
```

Output:

```text
/usr/bin/git
```

# Help for a Specific Command

For example:

```bash
git help commit
```

or

```bash
git commit --help
```

This opens the manual page for `git commit`.

---

# Quick Help

To see a short summary:

```bash
git commit -h
```

Example:

```text
usage: git commit [options]
```

This is useful when you only need the command syntax.

---

# Understanding Git Versions

Example:

```text
git version 2.50.1
```

This means:

|Part|Meaning|
|---|---|
|2|Major version|
|50|Minor version|
|1|Patch version|

For learning Git, the exact version usually doesn't matter as long as you're using a reasonably recent release.

# Common Installation Problems

## Problem 1

```text
git: command not found
```

**Solution**

Install Git using your package manager.

---

## Problem 2

Permission denied

**Solution**

Use `sudo` (Linux) when installing:

```bash
sudo apt install git
```

---

## Problem 3

Old Git Version

Update it:

```bash
sudo apt update
sudo apt upgrade git
```

# Git and PATH

When you type:

```bash
git
```

your shell searches the directories listed in the `PATH` environment variable.

View your `PATH`:

```bash
echo $PATH
```

Example:

```text
/usr/local/bin:/usr/bin:/bin
```

Since Git is usually installed in `/usr/bin`, the shell can find it automatically.

---

# Git Works Completely Offline

One of Git's biggest strengths is that you **do not need an internet connection** for most tasks.

You can:

- Create repositories
    
- Commit changes
    
- Create branches
    
- Merge branches
    
- View history
    
- Compare files
    

Internet is only needed when interacting with a remote service like GitHub.

---

# Terminal-First Mindset

As a backend engineer, you'll often work on remote Linux servers over SSH.

On those servers, you usually won't have a graphical interface.

Learning Git from the terminal means you'll be comfortable using it anywhere:

- Local machine
    
- Remote VPS
    
- Cloud servers
    
- Docker containers
    
- CI/CD environments
    

---

# Best Practices

- Keep Git updated.
    
- Learn Git commands instead of relying only on GUI tools.
    
- Use `git -h` or `git help <command>` whenever you're unsure.
    
- Verify installations after every setup.
