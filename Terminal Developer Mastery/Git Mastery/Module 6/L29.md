# What is GitHub Projects?

**GitHub Projects** is a project management tool built into GitHub.

It helps teams organize:

- GitHub Issues
    
- Pull Requests
    
- Draft tasks
    
- Roadmaps
    
- Releases
    

Instead of keeping tasks in spreadsheets or chat messages, everything stays connected to the code.

---

# Why Use Project Boards?

Imagine your team has 30 Issues.

Without a board:

```text
Issue #1

Issue #2

Issue #3

Issue #4

Issue #5

...

Issue #30
```

It's hard to know:

- What's finished?
    
- What's in progress?
    
- Who is working on what?
    
- What's blocked?
    

A Project Board solves this problem.

---

# Kanban Board

Most GitHub Projects use a **Kanban** layout.

Example:

```text
┌──────────┬──────────────┬─────────────┬─────────┐
│  Todo    │ In Progress  │ In Review   │  Done   │
├──────────┼──────────────┼─────────────┼─────────┤
│ Login    │ JWT Auth     │ API Docs    │ Docker  │
│ Profile  │ Dashboard    │             │ Tests   │
└──────────┴──────────────┴─────────────┴─────────┘
```

Each task is represented as a **card**.

As work progresses, cards move from left to right.

# Automation

GitHub Projects can automate repetitive actions.

Examples:

When an Issue is created:

```text
↓

Todo
```

When someone is assigned:

```text
↓

In Progress
```

When a PR is opened:

```text
↓

In Review
```

When the PR is merged:

```text
↓

Done
```

Automation reduces manual work and keeps the board accurate.

# Sprint Planning

Many Agile teams work in **Sprints** (often 1–2 weeks).

Sprint example:


# GitHub Projects vs Issues

|GitHub Issues|GitHub Projects|
|---|---|
|Individual tasks|Collection of tasks|
|Track one piece of work|Track the entire project|
|Bug or feature|Overall workflow|
|Discussion|Planning and organization|

They work best **together**, not as replacements.

---

|Feature|GitHub Projects|Trello|Jira|
|---|---|---|---|
|GitHub Integration|⭐⭐⭐⭐⭐|⭐⭐|⭐⭐⭐⭐|
|Code Linking|✅|❌|✅|

For most GitHub-based projects, GitHub Projects is an excellent starting point.

# Interview Questions

### 1. What is GitHub Projects?

GitHub Projects is a project management tool that organizes Issues, Pull Requests, and tasks into boards, tables, or roadmaps.

---

### 2. What is the purpose of a Kanban board?

A Kanban board visually tracks the progress of tasks through stages such as Todo, In Progress, In Review, and Done.

---

### 3. How are GitHub Projects and Issues related?

Issues represent individual tasks, while Projects organize and track many Issues throughout a project's lifecycle.

---

### 4. Why assign Issues to developers?

Assigning Issues clarifies ownership and responsibility, reducing confusion within the team.

---

### 5. What are the benefits of automation in GitHub Projects?

Automation keeps the project board up to date by automatically moving tasks based on events like Issue creation or Pull Request merging.
