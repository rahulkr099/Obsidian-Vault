# What is Git Configuration?

Git stores settings in configuration files.

These settings control:

- Your name
    
- Your email
    
- Default editor
    
- Default branch
    
- Colors
    
- Aliases
    
- Merge behavior
    
- Pull strategy
    
- And much more
    

Think of it as your personal Git preferences.

---

# Configuration Levels

Git has **three levels** of configuration.

|Level|Scope|File|
|---|---|---|
|System|All users on the computer|`/etc/gitconfig`|
|Global|Your user account|`~/.gitconfig`|
|Local|One specific repository|`.git/config`|

Priority:

```text
Local
   ↑
Global
   ↑
System
```

A local setting overrides a global setting, and a global setting overrides a system setting.

For most developers, you'll mainly use **global** and occasionally **local**.

---

# View Existing Configuration

Show all settings:

```bash
git config --list
```

Example:

```text
user.name=Rahul
user.email=rahul@example.com
core.editor=nvim
init.defaultBranch=main
color.ui=auto
```

---

# Configure Your Name

```bash
git config --global user.name "Rahul"
```

Replace `"Rahul"` with your real name.

Verify:

```bash
git config --global user.name
```

Output:

```text
Rahul
```

---

# Configure Your Email

```bash
git config --global user.email "you@example.com"
```

If you use GitHub, use the same email that is linked to your GitHub account.

Verify:

```bash
git config --global user.email
```

---

# Why Name and Email Matter

Every commit stores:

- Author name
    
- Email
    
- Date
    
- Commit message
    

Example:

```text
Author: Rahul <rahul@example.com>

Add JWT authentication middleware
```

This helps teams know who made each change.

---

# Set the Default Branch

Many repositories now use `main` instead of `master`.

Configure Git to create repositories with `main` by default:

```bash
git config --global init.defaultBranch main
```

Verify:

```bash
git config --global init.defaultBranch
```

Output:

```text
main
```

---

# Set Neovim as the Default Editor

Since you're already using **Neovim**, configure Git to use it.

```bash
git config --global core.editor "nvim"
```

Verify:

```bash
git config --global core.editor
```

Output:

```text
nvim
```

Now Git will open Neovim whenever you need to write a commit message, edit a merge message, or resolve certain operations.

---

# Enable Colored Output

Colored output makes Git easier to read.

```bash
git config --global color.ui auto
```

This is usually enabled by default, but it's good to set it explicitly.

---

# Useful Git Aliases

Aliases save typing and make your workflow faster.

### Status

```bash
git config --global alias.st status
```

Now:

```bash
git st
```

is the same as:

```bash
git status
```

---

### Log

```bash
git config --global alias.lg "log --oneline --graph --decorate"
```

Now:

```bash
git lg
```

Example output:

```text
* 4a7d8c2 Add login API
* 18b54ab Fix JWT bug
* 2c1e7f1 Initial commit
```

---

### Checkout Branch

```bash
git config --global alias.co checkout
```

Now:

```bash
git co main
```

---

### Branch

```bash
git config --global alias.br branch
```

---

### Commit

```bash
git config --global alias.cm commit
```

---

### Last Commit

```bash
git config --global alias.last "log -1 HEAD"
```

---

# View a Specific Setting

Instead of printing everything:

```bash

```

or

```bash

```

# Edit the Global Configuration

Open your Git config in Neovim:

```bash
git config --global --edit
```

You'll see something like:

```ini
[user]
    name = Rahul
    email = you@example.com

[core]
    editor = nvim

[init]
    defaultBranch = main

[color]
    ui = auto

[alias]
    st = status
    lg = log --oneline --graph --decorate
```

Save and quit just like any other Neovim file.

---

# Where is the Global Config Stored?

Display its location:

```bash
git config --global --list --show-origin
```

Example:

```text
file:/home/rahul/.gitconfig
```

You can also inspect it directly:

```bash
cat ~/.gitconfig
```

---

# Local Repository Configuration

Sometimes a project needs different settings.

Example:

```bash
git config user.name "Company Account"
git config user.email "dev@company.com"
```

Notice the absence of `--global`.

These settings apply **only to the current repository**.

---

# Remove a Setting

Suppose you want to remove an alias:

```bash
git config --global --unset alias.st
```

Verify:

```bash
git config --global --get alias.st
```

No output means it has been removed.

---

# Common Commands

|Command|Purpose|
|---|---|
|`git config --list`|Show all settings|
|`git config user.name`|Show username|
|`git config user.email`|Show email|
|`git config --global --edit`|Edit global config|
|`git config --global --unset`|Remove a setting|
|`git config --list --show-origin`|Show settings with source file|

---

# Best Practices

✅ Use your real name.

✅ Use the email connected to your GitHub account.

✅ Set `main` as the default branch.

✅ Use Neovim as your Git editor.

✅ Create aliases for commands you use often.

✅ Prefer global configuration for personal preferences and local configuration only when a specific repository needs different settings.
