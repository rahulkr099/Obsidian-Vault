# Backend Dockerfile

```docker
FROM node:22 AS builder

WORKDIR /app

COPY package*.json ./

RUN npm ci

COPY . .

RUN npm run build

FROM node:22-slim

WORKDIR /app

COPY package*.json ./

RUN npm ci --omit=dev && \
    useradd -m appuser

COPY --from=builder /app/dist ./dist

USER appuser

ENV NODE_ENV=production

EXPOSE 5000

CMD ["node","dist/server.js"]
```

# Frontend Dockerfile

```docker
FROM node:22 AS builder

WORKDIR /app

COPY . .

COPY --from=builder /app/dist \
```

# Nginx Reverse Proxy

Example:

```
server {
    listen 80;

    location / {
        proxy_pass <http://frontend>;
    }

    location /api {
        proxy_pass <http://backend:5000>;
    }
}
```

Nginx becomes the application's single public entry point.

---

# compose.yaml

```yaml
services:

  nginx:
    build: ./nginx
    ports:
      - "80:80"
    depends_on:
      - frontend
      - backend

  frontend:
    build: ./frontend

  backend:
    build: ./backend
    environment:
      MONGODB_URI: mongodb://mongodb:27017/app
      REDIS_URL: redis://redis:6379
    depends_on:
      - mongodb
      - redis

  mongodb:
    image: mongo:8
    volumes:
      - mongo-data:/data/db

  redis:
    image: redis:8

volumes:
  mongo-data:
```

# Environment Variables

Create:

```

```

```
JWT_SECRET=replace-me
```

# Health Endpoint

Backend:

```jsx
app.get("/health", (req, res) => {
    res.json({
        status: "healthy"
    });
});
```

Dockerfile:

```docker
HEALTHCHECK CMD wget --spider -q <http://localhost:5000/health> || exit 1
```

> If your runtime image doesn't include `wget`, use another suitable command or include a lightweight HTTP client.
