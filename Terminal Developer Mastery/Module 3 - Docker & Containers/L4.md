# Container Lifecycle

```
docker run
      │
      ▼
Created
      │
      ▼
Running
      │
      ▼
Stopped
      │
      ▼
Removed
```

Every container follows this lifecycle.

---

# Creating a Container

Basic syntax:

```
docker run IMAGE
```

Example:

```
docker run ubuntu:24.04
```

Docker will:

1. Check if image exists
2. Download it if necessary
3. Create container
4. Start container

---

# Interactive Mode

Linux containers usually need a shell.

```
docker run-it ubuntu:24.04
```

Options:

```
-i
Interactive input

-t
Terminal
```

Inside:

```
ls

pwd

whoami
```

Exit:

```
exit
```

---

# Detached Mode

Run in background:

```
docker run-d nginx
```

Output:

```
7adf234a...
```

Docker returns the container ID.

---

# Naming Containers

Instead of random names:

```
docker run--name my-nginx nginx
```

Now:

```
dockerstop my-nginx
```

Much easier.

---

# Mapping Ports

Without mapping:

```
localhost ❌
```

With mapping:

```
docker run-p8080:80 nginx
```

Meaning:

```
Host:8080

↓

Container:80
```

Visit:

```
<http://localhost:8080>
```

---

# Listing Containers

Running containers:

```
dockerps
```

Example:

```
CONTAINER ID

IMAGE

STATUS

PORTS

NAMES
```

---

# All Containers

Include stopped ones:

```
dockerps-a
```

Very useful while debugging.

---

# Stopping Containers

```
dockerstop my-nginx
```

Stops gracefully.

---

# Starting Again

```
dockerstart my-nginx
```

Starts existing container.

---

# Restarting

```
dockerrestart my-nginx
```

Equivalent to:

```
Stop

↓

Start
```

---

# Killing a Container

Immediate stop:

```
dockerkill my-nginx
```

Usually avoid unless necessary.

---

# Removing Containers

Container must be stopped:

```
dockerrm my-nginx
```

Remove forcefully:

```
dockerrm-f my-nginx
```

---

# Running Ephemeral Containers

Automatically delete after exit:

```
docker run--rm ubuntu
```

Perfect for:

- Testing
- Temporary scripts
- Quick experiments

# Executing Commands

Already running?

Open shell:

```
docker exec-it my-nginxbash
```

Ubuntu:

```
docker exec-it ubuntu-containerbash
```

Alpine:

```
docker exec-it alpinesh
```

---

# Viewing Logs

```
docker logs my-nginx
```

Follow logs:

```
docker logs-f my-nginx
```

Last 50 lines:

```
docker logs--tail50 my-nginx
```

---

# Inspecting Containers

```
docker inspect my-nginx
```

Shows:

- IP Address
- Ports
- Mounts
- Environment Variables
- Networks
- Labels

---

# Container Statistics

Real-time usage:

```
docker stats
```

Displays:

- CPU
- Memory
- Network I/O
- Block I/O

Great for performance monitoring.

---

# Copying Files

Host → Container

```
dockercp app.js my-nginx:/usr/share/nginx/html/
```

Container → Host

```
dockercp my-nginx:/etc/nginx/nginx.conf .
```

---

# Renaming Containers

```
docker rename old-name new-name
```

---

# Pausing Containers

Pause:

```
docker pause my-nginx
```

Resume:

```
docker unpause my-nginx
```

Useful for testing.

---

# Viewing Processes

```
dockertop my-nginx
```

Similar to:

```
ps
```

---

# Viewing Resource Usage

```
docker stats my-nginx
```

Example:

```
CPU

Memory

Network

Disk
```

---

# Removing Stopped Containers

```
docker container prune
```

Docker asks for confirmation.

---

# Best Practices

✅ Give meaningful names.

```
--name api
```

Instead of:

```
hopeful_brown
```

---

✅ Use detached mode for servers.

```
-d
```

---

✅ Use `--rm` for temporary containers.

---

✅ Check logs before restarting.

---

✅ Stop containers cleanly before removing them.

# Common Mistakes

❌ Forgetting port mapping.

```
docker run nginx
```

No browser access.

Correct:

```
docker run-p8080:80 nginx
```

---

❌ Confusing images and containers.

```
Image
↓

Create Container
↓

Run
```

---

❌ Deleting containers thinking images disappear.

They are separate.

# Cheat Sheet

```
# Run interactive
docker run-it ubuntu:24.04# Run detached
docker run-d nginx# Name container
docker run--name web nginx# Map ports
docker run-p8080:80 nginx# Running containers
dockerps# All containers
dockerps-a# Stop
dockerstop web# Start
dockerstart web# Restart
dockerrestart web# Kill
dockerkill web# Remove
dockerrm web# Execute shell
docker exec-it webbash# Logs
docker logs web
docker logs-f web# Stats
docker stats# Inspect
docker inspect web# Remove stopped containers
docker container prune
```
