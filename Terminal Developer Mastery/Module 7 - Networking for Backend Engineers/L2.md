# What is the TCP/IP Stack?

The **TCP/IP stack** is a set of networking rules (protocols) that computers use to communicate over a network.

Think of it like a postal system:

- You write a letter.
    
- Put it in an envelope.
    
- The post office delivers it.
    
- The receiver opens it and reads it.
    

Networking works similarly, but with **data** instead of letters.

---

# The Four Layers

The TCP/IP model has **4 layers**:

```text
+----------------------+
|  Application Layer   |
+----------------------+
|   Transport Layer    |
+----------------------+
|    Internet Layer    |
+----------------------+
|      Link Layer      |
+----------------------+
```

Each layer has a specific job.

---

# Overall Data Flow

Suppose your React frontend sends a request to your Express backend:

```text
Browser

↓

HTTP Request

↓

TCP

↓

IP

↓

Ethernet / Wi-Fi

↓

Internet

↓

Server
```

The response comes back through the same layers in reverse order.

---

# Layer 1 — Application Layer

This is the layer where applications communicate.

Examples:

- Browser
    
- Express.js
    
- Node.js
    
- Nginx
    
- curl
    
- Postman
    

Protocols:

- HTTP
    
- HTTPS
    
- FTP
    
- SSH
    
- SMTP
    
- DNS
    

Example:

```http
GET /users HTTP/1.1
Host: api.example.com
```

The browser creates an HTTP request.

At this point, it doesn't know how to send packets—it only knows how to create an application-level message.

---

# Layer 2 — Transport Layer

The Transport Layer is responsible for communication between applications.

Its main jobs are:

- Breaking data into segments
    
- Reliability
    
- Error checking
    
- Flow control
    
- Port numbers
    

There are two major protocols:

- TCP
    
- UDP
    

---

## TCP (Transmission Control Protocol)

TCP is reliable.

It guarantees:

- Correct order
    
- No missing data
    
- Error detection
    
- Retransmission if needed
    

Examples:

- HTTP
    
- HTTPS
    
- SSH
    
- Git
    
- Email
    

Think of TCP like a registered courier service that confirms delivery.

---

## UDP (User Datagram Protocol)

UDP is faster but does **not** guarantee delivery.

Examples:

- Online games
    
- Live video
    
- Voice calls
    
- DNS queries (usually)
    

Think of UDP like shouting a message across a room—you don't wait for confirmation.

---

# Ports

Transport Layer uses **ports**.

Example:

```text
Computer

Port 80  → HTTP

Port 443 → HTTPS

Port 22  → SSH

Port 3306 → MySQL

Port 5432 → PostgreSQL

Port 6379 → Redis
```

The IP address identifies the machine, while the port identifies the specific application on that machine.

Example:

```text
192.168.1.10:5000
```

- IP → Computer
    
- Port → Express server
    

---

# Layer 3 — Internet Layer

The Internet Layer is responsible for routing packets between networks.

Protocol:

- IP (Internet Protocol)
    

Its responsibilities include:

- Source IP
    
- Destination IP
    
- Routing
    
- Packet forwarding
    

Example:

```text
Source:
192.168.1.20

↓

Destination:
142.250.xxx.xxx
```

Routers inspect the destination IP and decide the next hop.

---

# Layer 4 — Link Layer

This layer sends data over the physical network.

Examples:

- Ethernet
    
- Wi-Fi
    
- Fiber
    
- Cable
    

It handles communication between devices on the same local network.

Each network device has a **MAC address**, which is used at this layer.

Example:

```text
Laptop

↓

Wi-Fi

↓

Router

↓

Ethernet

↓

ISP
```

---

# How Data Travels

Imagine you visit:

```text
https://google.com
```

### Step 1

Browser creates:

```http
GET /
```

Application Layer

↓

### Step 2

TCP adds:

- Source port
    
- Destination port
    
- Sequence number
    
- Checksum
    

↓

### Step 3

IP adds:

- Source IP
    
- Destination IP
    

↓

### Step 4

Ethernet/Wi-Fi adds:

- Source MAC
    
- Destination MAC
    

↓

### Step 5

Packet travels across the network.

---

# Encapsulation

Each layer adds its own information before sending the data.

```text
Application Data

↓

TCP Header

↓

IP Header

↓

Ethernet Header

↓

Network
```

This process is called **encapsulation**.

---

# Decapsulation

At the destination, the reverse happens.

```text
Network

↓

Ethernet Header Removed

↓

IP Header Removed

↓

TCP Header Removed

↓

HTTP Request
```

This is called **decapsulation**.

# TCP/IP vs OSI Model

You will often hear about the **OSI Model** in interviews.

### OSI Model (7 Layers)

```text
7 Application
6 Presentation
5 Session
4 Transport
3 Network
2 Data Link
1 Physical
```

---

### TCP/IP Model (4 Layers)

```text
Application

Transport

Internet

Link
```

---

# Mapping OSI to TCP/IP

|OSI Layer|TCP/IP Layer|
|---|---|
|Application|Application|
|Presentation|Application|
|Session|Application|
|Transport|Transport|
|Network|Internet|
|Data Link|Link|
|Physical|Link|

---

# Why TCP/IP Is Used More

The OSI model is mainly used for learning concepts.

The TCP/IP model is used in real-world networking because it describes the protocols that power the Internet.

# Common Interview Questions

### 1. What is the TCP/IP stack?

The TCP/IP stack is a four-layer networking model that defines how devices communicate over networks using standardized protocols.

---

### 2. What are the four TCP/IP layers?

- Application
    
- Transport
    
- Internet
    
- Link
    

---

### 3. What is the difference between TCP and UDP?

|TCP|UDP|
|---|---|
|Reliable|Best effort|
|Connection-oriented|Connectionless|
|Ordered delivery|No ordering guarantee|
|Retransmits lost data|No retransmission|
|Used by HTTP, HTTPS, SSH|Used by gaming, streaming, DNS (commonly)|

---

### 4. What is encapsulation?

Encapsulation is the process where each TCP/IP layer adds its own header to the data before sending it across the network.

---

### 5. Why does TCP use ports?

Ports allow multiple applications on the same computer to communicate over the network at the same time. The IP address identifies the host, and the port identifies the specific service or application.

---

# Key Takeaways

- The **TCP/IP stack** is the foundation of Internet communication.
    
- It has **4 layers**: Application, Transport, Internet, and Link.
    
- The **Application Layer** creates requests (HTTP, DNS, SSH).
    
- The **Transport Layer** uses TCP or UDP and identifies applications with ports.
    
- The **Internet Layer** uses IP addresses to route packets between networks.
    
- The **Link Layer** sends frames over technologies like Ethernet and Wi-Fi.
    
- **Encapsulation** adds headers as data moves down the stack, and **decapsulation** removes them at the destination.
    
- The **OSI model** is a conceptual seven-layer model, while **TCP/IP** is the practical model used on the Internet.
