# What is an IP Address?

An **IP address** is a unique identifier assigned to a device on a network.

It helps other devices know:

- Who sent the data
    
- Where to send the reply
    

Think of sending a package.

```text
Sender:
Rahul

Receiver:
John
```

Without an address, the package can't be delivered.

The same is true for computers.

---

# Example

Your laptop:

```text
IP Address:
192.168.1.20
```

Your router:

```text
192.168.1.1
```

Google server:

```text
142.250.xxx.xxx
```

Every device has its own address.

---

# IPv4

IPv4 is the most widely used IP version today.

Format:

```text
192.168.1.20
```

It consists of **4 numbers** separated by dots.

Each number ranges from:

```text
0–255
```

Example:

```text
172.16.25.100
```

---

# IPv4 Structure

```text
192 . 168 . 1 . 20
 │      │    │    │
Octet Octet Octet Octet
```

Each octet contains **8 bits**.

Total:

```text
8 × 4 = 32 bits
```

So IPv4 is a **32-bit address**.

---

# Binary Representation

Computers understand binary.

Example:

```text
192.168.1.20
```

becomes

```text
11000000
10101000
00000001
00010100
```

You don't need to memorize binary values, but it's useful to know that IP addresses are stored this way.

---

# IPv6

IPv6 was introduced because the world ran out of IPv4 addresses.

Example:

```text
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

IPv6 has:

- 128 bits
    
- Much larger address space
    
- Better scalability
    
- Built-in support for modern networking features
    

---

# Shortened IPv6

IPv6 addresses can be shortened.

Instead of:

```text
2001:0db8:0000:0000:0000:0000:1428:57ab
```

You can write:

```text
2001:db8::1428:57ab
```

The `::` represents one or more groups of consecutive zeros, but it can only appear **once** in an IPv6 address.

---

# IPv4 vs IPv6

|Feature|IPv4|IPv6|
|---|---|---|
|Length|32 bits|128 bits|
|Format|Dotted decimal|Hexadecimal|
|Example|192.168.1.20|2001:db8::1|
|Address Space|~4.3 billion|Extremely large|
|NAT Required|Often|Usually not|

---

# Public IP Address

A **public IP** is reachable from the Internet.

Example:

```text
103.25.45.18
```

Web servers and cloud servers typically have public IPs.

Example:

```text
Internet

↓

Cloud Server

↓

Public IP
```

---

# Private IP Address

Private IPs are used inside local networks.

They are **not reachable directly** from the Internet.

Private IP ranges:

```text
10.0.0.0 – 10.255.255.255
```

```text
172.16.0.0 – 172.31.255.255
```

```text
192.168.0.0 – 192.168.255.255
```

Example:

```text
Laptop

↓

192.168.1.20
```

---

# Why Use Private IPs?

Imagine an office with 300 computers.

Giving every computer a public IP would be expensive and unnecessary.

Instead:

```text
PC1

192.168.1.10

PC2

192.168.1.11

PC3

192.168.1.12
```

All devices share one public IP through **NAT (Network Address Translation)**.

---

# Loopback Address

The loopback address points back to the same computer.

IPv4:

```text
127.0.0.1
```

Common hostname:

```text
localhost
```

Example:

```text
Browser

↓

127.0.0.1

↓

Express Server
```

No network cable or Wi-Fi is involved. The traffic never leaves your computer.

---

# Why Backend Developers Use localhost

During development:

```text
http://localhost:3000
```

or

```text
http://127.0.0.1:5000
```

Your browser communicates with a server running on the same machine.

---

# Broadcast Address

A **broadcast address** sends a message to **every device on the local network**.

Example network:

```text
192.168.1.0/24
```

Broadcast address:

```text
192.168.1.255
```

If a packet is sent there:

```text
Laptop

↓

192.168.1.255

↓

Every device receives it
```

Broadcasting is limited to the local network and is not routed across the Internet.

---

# Default Gateway

The **default gateway** is the router that forwards traffic to other networks.

Example:

```text
Laptop

192.168.1.20

↓

Gateway

192.168.1.1

↓

Internet
```

When your computer doesn't know how to reach a destination, it sends the packet to the default gateway.

---

# Real Example

Suppose you visit:

```text
https://google.com
```

Your computer knows:

```text
My IP:
192.168.1.20
```

Google:

```text
142.250.xxx.xxx
```

These addresses are on different networks.

So your computer sends the packet to:

```text
192.168.1.1
```

(the router)

The router forwards it toward Google.

---

# Special IPv4 Addresses

|Address|Purpose|
|---|---|
|127.0.0.1|Loopback|
|0.0.0.0|Unspecified address / all local interfaces (context-dependent)|
|255.255.255.255|Limited broadcast|
|192.168.x.x|Private network|
|10.x.x.x|Private network|
|172.16.x.x – 172.31.x.x|Private network|

# Introduction to CIDR

You'll study this in detail in Lesson 4.

Example:

```text
192.168.1.0/24
```

Meaning:

- Network: `192.168.1.0`
    
- `/24` means the first **24 bits** identify the network.
    

This notation defines the network size and available host addresses.

# Linux Commands

## View all IP addresses

```bash
ip addr
```

Example:

```text
2: wlp2s0:
    inet 192.168.1.20/24
```

Here:

- `inet` = IPv4 address
    
- `/24` = CIDR prefix
    

---

## Show only IP addresses

```bash
hostname -I
```

Example:

```text
192.168.1.20
```

---

## Show your public IP

```bash
curl ifconfig.me
```

Example:

```text
49.xxx.xxx.xxx
```

This queries an external service to tell you the public IP seen on the Internet.

---

## View routing information

```bash
ip route
```

Example:

```text
default via 192.168.1.1 dev wlp2s0

192.168.1.0/24 dev wlp2s0
```

Meaning:

- Default gateway: `192.168.1.1`
    
- Local network: `192.168.1.0/24`

# Real Backend Example

Imagine your Express server is running on port `5000`:

```javascript
app.listen(5000);
```

When you open:

```text
http://localhost:5000
```

the request goes to:

```text
127.0.0.1

↓

TCP Port 5000

↓

Express Server
```

If you instead use:

```text
http://192.168.1.20:5000
```

other devices on the same LAN may also be able to access your server, provided your firewall and application configuration allow it.

# Common Interview Questions

### 1. What is an IP address?

An IP address is a unique identifier assigned to a device on a network so it can send and receive data.

---

### 2. What is the difference between IPv4 and IPv6?

IPv4 uses 32-bit addresses in dotted-decimal format, while IPv6 uses 128-bit hexadecimal addresses, providing a vastly larger address space.

---

### 3. What is the loopback address?

The IPv4 loopback address is `127.0.0.1`. It refers to the local machine and is commonly accessed through the hostname `localhost`.

---

### 4. What is a default gateway?

The default gateway is the router that forwards packets from your local network to other networks, such as the Internet.

---

### 5. Why are private IP addresses used?

Private IP addresses allow many devices within a local network to communicate internally and share a smaller number of public IP addresses through NAT.

---

# Key Takeaways

- Every networked device needs an **IP address**.
    
- **IPv4** is a 32-bit addressing scheme; **IPv6** is a 128-bit addressing scheme designed to support a much larger number of devices.
    
- **Public IPs** are Internet-routable; **private IPs** are used inside local networks.
    
- **127.0.0.1 (localhost)** always refers to your own computer.
    
- The **default gateway** forwards traffic outside your local network.
    
- The `ip`, `hostname`, `curl`, and `ping` commands are essential tools for inspecting and testing IP connectivity.
