# What is a Network Interface?

A **network interface** is how Linux sends and receives network traffic.

Think of it as a **door** through which data enters and leaves your computer.

Example:

```text
                Internet
                    │
                    ▼
             Wi-Fi Router
                    │
                    ▼
          ┌─────────────────┐
          │ Linux Computer  │
          │                 │
          │ Interface       │
          │ (wlp2s0)        │
          └─────────────────┘
```

Every packet goes through an interface.

---

# One Computer Can Have Multiple Interfaces

A computer can have several interfaces.

Example:

```text
Laptop

├── lo
├── wlp2s0
├── enp0s31f6
├── docker0
└── vethxxxx
```

Each serves a different purpose.

---

# Physical Interfaces

Physical interfaces are backed by actual hardware.

Examples:

- Ethernet cable
    
- Wi-Fi adapter
    
- USB network adapter
    

---

## Ethernet

Ethernet uses a wired cable.

Common Linux names:

```text
eth0
enp0s3
enp5s0
```

Example:

```text
PC

↓

Ethernet Cable

↓

Router
```

Advantages:

- Fast
    
- Stable
    
- Low latency
    

Perfect for servers.

---

## Wi-Fi

Wireless interface.

Typical names:

```text
wlan0

wlp2s0

wlp3s0
```

Example:

```text
Laptop

)))

Wi-Fi

)))

Router
```

Advantages:

- Convenient
    
- Mobile
    

Disadvantages:

- More interference
    
- Usually less stable than wired Ethernet
    

---

# Virtual Interfaces

Linux can create interfaces that don't correspond to physical hardware.

Examples:

- Docker
    
- Virtual Machines
    
- VPNs
    
- Network namespaces
    

These are software-created interfaces.

---

# Loopback Interface

The most important virtual interface.

Name:

```text
lo
```

Address:

```text
127.0.0.1
```

Traffic sent to `127.0.0.1` never leaves your computer.

Example:

```text
Browser

↓

127.0.0.1

↓

Express Server
```

---

# Why Loopback Exists

Suppose your API runs locally:

```text
http://localhost:5000
```

The request flows:

```text
Browser

↓

lo

↓

Express Server
```

No router.

No Wi-Fi.

No Internet.

Everything stays inside the operating system.

---

# Docker Interface

When Docker is installed:

```bash
ip addr
```

You may see:

```text
docker0
```

Example:

```text
Laptop

├── wlp2s0
├── lo
└── docker0
```

This is Docker's bridge interface.

Containers connect through it.

---

# Virtual Ethernet (veth)

Docker containers communicate using **veth pairs**.

Think of a veth pair as a **virtual network cable**.

```text
Container

↓

veth123

========

veth456

↓

docker0

↓

Host
```

One end stays inside the container.

The other stays on the host.

---

# Bridge Interface

A bridge works like a **virtual switch**.

Example:

```text
Container A

↓

Bridge

↓

Container B

↓

Host
```

The bridge allows devices to communicate as if they were connected to the same switch.

Docker's default bridge:

```text
docker0
```

---

# Common Interface Names

|Interface|Purpose|
|---|---|
|lo|Loopback|
|eth0|Ethernet (older naming)|
|enp0s3|Ethernet (predictable naming)|
|wlan0|Wi-Fi (older naming)|
|wlp2s0|Wi-Fi (predictable naming)|
|docker0|Docker bridge|
|vethXXXX|Virtual Ethernet|
|br0|Linux bridge|
|tun0|VPN tunnel|
|tap0|Virtual machine networking|

---

# Why Interface Names Changed

Older Linux systems used:

```text
eth0

eth1

wlan0
```

Modern Linux uses **predictable network interface names**.

Examples:

```text
enp0s3

enp5s0

wlp2s0
```

This prevents interface names from changing unexpectedly after hardware changes.

# Viewing Interfaces

## Show all interfaces

```bash
ip link
```

Example:

```text
1: lo

2: wlp2s0

3: docker0
```

---

## Show IP addresses

```bash
ip addr
```

Example:

```text
2: wlp2s0

inet 192.168.1.20/24
```

---

## Show only active interfaces

```bash
ip -br addr
```

Example:

```text
lo        UNKNOWN 127.0.0.1/8
wlp2s0    UP      192.168.1.20/24
docker0   DOWN    172.17.0.1/16
```

This "brief" view is often easier to read.

---

# Bring an Interface Down

Temporarily disable:

```bash
sudo ip link set wlp2s0 down
```

Re-enable:

```bash
sudo ip link set wlp2s0 up
```

Be careful when running these commands remotely over SSH—you can disconnect yourself.

# Interface States

Interfaces can have different states.

|State|Meaning|
|---|---|
|UP|Ready to send and receive traffic|
|DOWN|Disabled|
|UNKNOWN|Often normal for loopback or virtual interfaces|
|DISCONNECTED|No network connection|

# Real Backend Example

Suppose you're running an Express server:

```javascript
app.listen(5000);
```

If it listens only on:

```text
127.0.0.1
```

Only the local machine can access it.

If it listens on:

```text
0.0.0.0
```

The server accepts connections on **all network interfaces** (subject to firewall rules).

Example:

```text
Laptop

Interfaces

├── lo
├── wlp2s0
└── docker0

↓

Express listens on

0.0.0.0

↓

Accessible through all active interfaces
```

This is why, when testing from another device on your LAN, you often use:

```text
http://192.168.1.20:5000
```

instead of:

```text
http://localhost:5000
```

# Common Interview Questions

### 1. What is a network interface?

A network interface is the operating system's connection point for sending and receiving network traffic.

---

### 2. What is the loopback interface?

The loopback interface (`lo`) is a virtual interface that allows a computer to communicate with itself using addresses such as `127.0.0.1`.

---

### 3. What is the difference between a physical and a virtual interface?

|Physical Interface|Virtual Interface|
|---|---|
|Backed by hardware|Created by software|
|Ethernet, Wi-Fi|Docker bridge, VPN, loopback, veth|

---

### 4. What is `docker0`?

`docker0` is Docker's default bridge interface, used to connect containers on the host.

---

### 5. Why is `ip` preferred over `ifconfig`?

The `ip` command is part of the modern `iproute2` suite. It supports more networking features and is the recommended replacement for `ifconfig`.

# Key Takeaways

- A **network interface** is the operating system's connection point to a network.
    
- **Physical interfaces** include Ethernet and Wi-Fi adapters.
    
- **Virtual interfaces** include `lo`, `docker0`, VPN tunnels, and `veth` pairs.
    
- The **loopback interface (`lo`)** allows a computer to communicate with itself.
    
- **Docker** uses bridge and virtual Ethernet interfaces to connect containers.
    
- The `ip` command is the primary tool for inspecting and managing Linux networking.
