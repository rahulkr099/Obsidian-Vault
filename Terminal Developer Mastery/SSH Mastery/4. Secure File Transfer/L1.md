# What is SCP?

**SCP (Secure Copy Protocol)** is a command-line tool used to securely copy files and directories between computers over an SSH connection.

Think of it as:

> **`cp` + SSH = `scp`**

- `cp` copies files on the **same computer**
- `scp` copies files **between different computers securely**

---

# Why use SCP?

Suppose you built your MERN application on your laptop.

Now you want to upload it to your Linux server.

Without SCP, you might:

- Use a USB drive ❌
- Use email ❌
- Use cloud storage ❌

Instead:

```bash
scp project.zip user@server:/home/user/
```

Done. Secure and encrypted.

---

# How SCP Works

```
Local Computer
      │
      │
Encrypted SSH Connection
      │
      ▼
Remote Linux Server
```

Everything is encrypted while being transferred.

---

# SCP Uses SSH

SCP does **not** create its own secure connection.

Instead, it uses:

```
SSH Authentication
SSH Encryption
SSH Keys
SSH Port
```

So if SSH works:

```bash
ssh user@server
```

then SCP usually works too.

---

# Basic Syntax

```bash
scp [options] source destination
```

Example:

```bash
scp file.txt user@192.168.1.20:/home/user/
```

Read it like:

```
Copy

file.txt

to

192.168.1.20

inside

/home/user/
```

---

# Local → Remote

```
Laptop
   │
   │ file.txt
   ▼
Linux Server
```

Command:

```bash
scp file.txt user@server:/home/user/
```

---

# Remote → Local

```
Linux Server
      │
      │ logs.txt
      ▼
Laptop
```

Command:

```bash
scp user@server:/var/log/syslog .
```

The `.` means:

> Current directory.

---

# Remote → Remote

SCP can even copy files **between two remote servers**.

```
Server A
    │
    │
    ▼
Server B
```

Example:

```bash
scp user1@server1:/backup.sql user2@server2:/backup/
```

This is useful when migrating servers.

---

# SCP vs CP

## cp

Copies inside one computer.

```bash
cp notes.txt backup/
```

No network involved.

---

## scp

Copies over the network.

```bash
scp notes.txt user@server:/backup/
```

Uses SSH.

---

# SCP vs SFTP

|SCP|SFTP|
|---|---|
|One command|Interactive session|
|Fast|Good for browsing|
|Copy only|File management|
|Simple|Many commands|

SCP example:

```bash
scp file.txt user@server:/tmp/
```

SFTP example:

```bash
sftp user@server
```

Then:

```bash
put file.txt
get log.txt
ls
pwd
```

---

# SCP vs rsync

|SCP|rsync|
|---|---|
|Copies everything|Copies only changes|
|Slower for repeated transfers|Very fast after first sync|
|Simpler|More powerful|
|Good for one-time copy|Best for deployments|

Example:

SCP uploads the whole project every time.

```
Project
100 MB
```

Changed one file?

SCP uploads:

```
100 MB
```

---

rsync uploads only:

```
Changed file
2 KB
```

Much faster.

# Common SCP Options

## `r`

Recursive copy (directories)

```bash
scp -r project user@server:/var/www/
```

---

## `P`

Specify SSH port.

```bash
scp -P 2222 file.txt user@server:/tmp/
```

**Note:** It's uppercase `P`. Lowercase `-p` means something different.

---

## `p`

Preserve:

- timestamps
- permissions
- modification time

```bash
scp -p file.txt user@server:/backup/
```

---

## `C`

Compression.

```bash
scp -C backup.sql user@server:/backup/
```

Useful over slow networks.

---

## `v`

Verbose mode.

```bash
scp -v file.txt user@server:/tmp/
```

Shows what SCP is doing, which is helpful for debugging.

As you advance, you'll often replace SCP with `rsync` for deployments because it's faster, but SCP is still excellent for quick transfers.

---

# Best Practices

- Use SSH keys instead of passwords.
- Verify the destination path before copying.
- Use `r` only when copying directories.
- Use `C` for large transfers on slow connections.
- Use `v` when troubleshooting.
- Prefer `rsync` for frequent project deployments.

---

# Quick Summary

|Command|Purpose|
|---|---|
|`scp file user@host:/path/`|Upload a file|
|`scp user@host:/path/file .`|Download a file|
|`scp -r dir user@host:/path/`|Upload a directory|
|`scp -P 2222 file user@host:/path/`|Use a custom SSH port|
|`scp -p file user@host:/path/`|Preserve file metadata|
|`scp -C file user@host:/path/`|Compress during transfer|
|`scp -v file user@host:/path/`|Verbose output|

# Practice Exercises

1. Create a test file:
    
    ```bash
    echo "Hello SCP" > hello.txt
    ```
    
2. If you have access to a remote Linux server, upload it:
    
    ```bash
    scp hello.txt username@server:/home/username/
    ```
    
3. Download it back with a different name:
    
    ```bash
    scp username@server:/home/username/hello.txt hello_copy.txt
    ```
    
4. Compare the files:
    
    ```bash
    diff hello.txt hello_copy.txt
    ```
    

If `diff` produces no output, the files are identical.
