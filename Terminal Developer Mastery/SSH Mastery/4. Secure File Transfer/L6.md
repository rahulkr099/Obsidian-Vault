# Module 4 — Lesson 6: SFTP Commands (`put`, `get`, `ls`, `cd`)

In Lesson 5, you learned how to connect to a server using SFTP.

Now you'll learn the commands you'll use **inside an SFTP session** to manage files and directories.

Think of SFTP as a mini file manager that runs in your terminal.

---

# Learning Objectives

By the end of this lesson, you'll be able to:

- Upload files (`put`)
- Download files (`get`)
- List remote and local files (`ls`, `lls`)
- Navigate directories (`cd`, `lcd`)
- Show current directories (`pwd`, `lpwd`)
- Create directories (`mkdir`, `lmkdir`)
- Remove directories (`rmdir`)
- Rename files (`rename`)
- Delete files (`rm`)
- Use wildcards

---

# Starting an SFTP Session

Connect to the server:

```bash
sftp user@server
```

You'll see:

```
Connected to server.

sftp>
```

All commands below are typed at the `sftp>` prompt.

---

# Remote vs Local Commands

|Remote|Local|
|---|---|
|`ls`|`lls`|
|`cd`|`lcd`|
|`pwd`|`lpwd`|
|`mkdir`|`lmkdir`|

A simple rule:

> Commands starting with **`l`** affect your **Local** computer.

---

# 1. `ls` — List Remote Files

Show files on the server:

```
sftp> ls
```

Example:

```
app.js
package.json
README.md
logs/
uploads/
```

---

# Long Listing

```
sftp> ls -l
```

Example:

```
-rw-r--r-- app.js
-rw-r--r-- package.json
drwxr-xr-x logs
```

Similar to:

```bash
ls -l
```

in Linux.

---

# List Hidden Files

```
sftp> ls -a
```

Example:

```
.
..
.env
.gitignore
app.js
```

---

# 2. `lls` — List Local Files

Show files on your own computer:

```
sftp> lls
```

Example:

```
Desktop
Downloads
Projects
notes.txt
```

---

# 3. `pwd` — Remote Current Directory

```
sftp> pwd
```

Example:

```
Remote working directory:
/home/rahul
```

---

# 4. `lpwd` — Local Current Directory

```
sftp> lpwd
```

Example:

```
Local working directory:
/home/rahul/projects
```

---

# 5. `cd` — Change Remote Directory

Current:

```
/home/rahul
```

Move:

```
sftp> cd project
```

Now:

```
sftp> pwd
```

Output:

```
/home/rahul/project
```

---

# Go Back

```
sftp> cd ..
```

Move up one directory.

---

# Go Home

```
sftp> cd
```

Returns to your remote home directory.

---

# 6. `lcd` — Change Local Directory

Current:

```
/home/rahul
```

Move:

```
sftp> lcd ~/Downloads
```

Check:

```
sftp> lpwd
```

Output:

```
/home/rahul/Downloads
```

---

# 7. `put` — Upload a File

Upload from your computer to the server.

```
sftp> put app.js
```

Meaning:

```
Local Computer
      │
      ▼
Remote Server
```

Output:

```
Uploading app.js
```

---

# Upload with Another Name

```
sftp> put app.js server.js
```

Local:

```
app.js
```

Remote:

```
server.js
```

---

# Upload Multiple Files

```
sftp> put *.js
```

Uploads:

```
app.js
config.js
server.js
```

---

# Upload a Directory

Use `-r`:

```
sftp> put -r project
```

Everything inside:

```
project/
src/
public/
config/
```

gets uploaded.

---

# 8. `get` — Download a File

Download from server:

```
sftp> get app.log
```

Meaning:

```
Remote Server
      │
      ▼
Local Computer
```

---

# Download with Another Name

```
sftp> get access.log nginx-access.log
```

Remote:

```
access.log
```

Local:

```
nginx-access.log
```

---

# Download Multiple Files

```
sftp> get *.txt
```

Downloads:

```
README.txt
notes.txt
todo.txt
```

---

# Download a Directory

```
sftp> get -r project
```

Downloads everything recursively.

---

# 9. `mkdir` — Create Remote Directory

```
sftp> mkdir uploads
```

Result:

```
uploads/
```

created on the server.

---

# 10. `lmkdir` — Create Local Directory

```
sftp> lmkdir backups
```

Creates:

```
backups/
```

on your computer.

---

# 11. `rmdir` — Remove Remote Directory

```
sftp> rmdir old-folder
```

Works **only if the directory is empty**.

---

# 12. `rm` — Delete Remote File

```
sftp> rm old.log
```

Deletes:

```
old.log
```

from the server.

⚠️ There is **no recycle bin**. Deletion is immediate.

---

# 13. `rename` — Rename a Remote File

```
sftp> rename old.txt new.txt
```

Result:

```
old.txt
```

becomes:

```
new.txt
```

---

# 14. `chmod` — Change Remote Permissions

```
sftp> chmod 644 app.js
```

Example:

Before:

```
-rwx------
```

After:

```
-rw-r--r--
```

---

# 15. `chown` — Change Owner

If permitted:

```
sftp> chown www-data app.js
```

Usually requires appropriate privileges.

---

# 16. `chgrp` — Change Group

```
sftp> chgrp developers app.js
```

Again, this depends on your server permissions.

---

# Complete Example Session

```
sftp> pwd
/home/rahul

sftp> ls
project
logs

sftp> cd project

sftp> put app.js

sftp> put package.json

sftp> mkdir uploads

sftp> ls

app.js
package.json
uploads

sftp> get app.js

sftp> rename app.js server.js

sftp> rm old.log

sftp> exit
```

# Real-World Example

Suppose your server has:

```
my-api/

server.js
package.json
logs/
uploads/
```

Workflow:

```
sftp user@server

cd my-api

put server.js

put package.json

get logs/error.log

mkdir backups

rename server.js old-server.js

exit
```

No need to reconnect for every action.

# Common Errors

## File Not Found

```
Couldn't stat remote file
```

Check:

```
ls
pwd
```

---

## Permission Denied

```
Permission denied
```

Possible causes:

- No write permission
- Wrong user
- Protected directory

---

## Directory Not Empty

```
Failure
```

when running:

```
rmdir uploads
```

Reason:

The directory still contains files.

---

## Upload Failed

Check:

```
lpwd
lls
```

You may be in the wrong local directory.

# SFTP Command Cheat Sheet

|Command|Purpose|
|---|---|
|`ls`|List remote files|
|`lls`|List local files|
|`pwd`|Show remote directory|
|`lpwd`|Show local directory|
|`cd dir`|Change remote directory|
|`lcd dir`|Change local directory|
|`put file`|Upload a file|
|`put -r dir`|Upload a directory|
|`get file`|Download a file|
|`get -r dir`|Download a directory|
|`mkdir dir`|Create remote directory|
|`lmkdir dir`|Create local directory|
|`rm file`|Delete remote file|
|`rmdir dir`|Remove empty remote directory|
|`rename old new`|Rename a remote file|
|`chmod 644 file`|Change remote permissions|
|`exit`|Disconnect|

# Best Practices

- Always run `pwd` before uploading so you know where files will go.
- Use `lpwd` to confirm your local working directory before downloading.
- Verify files with `ls` after uploads or downloads.
- Be cautious with `rm` because deleted files cannot be recovered through SFTP.
- Prefer SSH keys over passwords for authentication.
