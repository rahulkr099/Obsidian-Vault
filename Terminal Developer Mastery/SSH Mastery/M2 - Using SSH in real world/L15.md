## Keep Connections Alive

```
Host *
    ServerAliveInterval 60
    ServerAliveCountMax 3
```

---

## Faster Connections

```
Host *
    ControlMaster auto
    ControlPersist 10m
    ControlPath ~/.ssh/control-%r@%h:%p
```

# Security Best Practices

## ✅ Use SSH Keys

Preferred:

```
SSH Keys
```

Avoid when possible:

```
Passwords
```

---

## ✅ Protect Your Private Key

Good permissions:

```bash
chmod 600 ~/.ssh/id_ed25519
```

Never share:

```
id_ed25519
```

You may share:

```
id_ed25519.pub
```

---

## ✅ Use Strong Passphrases

Protect your private key with a passphrase whenever practical.

If someone copies your key file, the passphrase adds another layer of protection.

---

## ✅ Verify Host Keys

When connecting to a new server:

```
The authenticity of host...
```

Verify the fingerprint if possible before accepting it.

Avoid automatically disabling host-key verification unless you're in a controlled environment.

---

## ✅ Keep Software Updated

Update OpenSSH regularly:

```bash
sudo apt update
sudo apt upgrade
```

# Most Common SSH Errors

|Error|First Thing to Check|
|---|---|
|Connection refused|Is the SSH service running?|
|Connection timed out|Firewall or security group|
|Permission denied|Username and SSH key|
|Host key verification failed|`known_hosts` entry|
|Broken pipe|Keep-alive settings|
|Could not resolve hostname|DNS or SSH config|

# Interview Questions

## Question 1

**What is SSH?**

Good answer:

> SSH (Secure Shell) is a secure protocol used to remotely access and manage computers over an encrypted connection. It also supports secure file transfer and remote command execution.

---

## Question 2

**Difference between SSH and Telnet?**

|SSH|Telnet|
|---|---|
|Encrypted|Unencrypted|
|Secure|Insecure|
|Default Port 22|Default Port 23|

---

## Question 3

**What is public-key authentication?**

A public/private key pair is generated.

- Public key → stored on the server.
- Private key → kept securely on the client.

The server verifies that the client possesses the matching private key without the private key ever being sent across the network.

---

## Question 4

**What does `ssh -vvv` do?**

It enables maximum verbose logging, making it easier to diagnose connection and authentication issues.

---

## Question 5

**What is `~/.ssh/config`?**

A user-specific configuration file that stores SSH connection settings such as host aliases, usernames, ports, identity files, and connection options.

---

## Question 6

**Difference between `scp` and `rsync`?**

|`scp`|`rsync`|
|---|---|
|Copies files directly|Synchronizes directories efficiently|
|Copies everything each time|Transfers only changed data|
|Simpler|Better for repeated deployments|

---

## Question 7

**Why use `ServerAliveInterval`?**

To reduce the chance that idle SSH connections are closed by intermediate network devices.

---

## Question 8

**What is SSH Agent?**

An SSH agent securely stores decrypted private keys in memory so you don't have to re-enter the passphrase for every connection.
