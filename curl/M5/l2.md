# What is HTML?

**HTML (HyperText Markup Language)** is the standard language used to create webpages.

It uses **tags** to describe content.

Example:

```html
<h1>Welcome</h1>

<p>This is my website.</p>

<a href="https://example.com">Visit</a>
```

Here:

- `<h1>` → Main heading
    
- `<p>` → Paragraph
    
- `<a>` → Link
    

---

# HTML Structure

A simple webpage looks like this:

```html
<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>Learning curl scraping.</p>

</body>

</html>
```

Structure:

```text
html
├── head
│     └── title
│
└── body
      ├── h1
      └── p
```

Most of the content you want to scrape is inside the `<body>` tag.

---

# Download HTML Using curl

```bash
curl -s https://example.com
```

Example output:

```html
<!doctype html>

<html>

<head>

<title>Example Domain</title>

</head>

<body>

<div>

<h1>Example Domain</h1>

<p>This domain is for use in documentation.</p>

</div>

</body>

</html>
```

This is the raw HTML that your scraper works with.

# HTML Tags

Some common tags you'll encounter:

|Tag|Purpose|
|---|---|
|`<h1>`|Main heading|
|`<h2>`|Subheading|
|`<p>`|Paragraph|
|`<a>`|Link|
|`<img>`|Image|
|`<table>`|Table|
|`<tr>`|Table row|
|`<td>`|Table cell|
|`<div>`|Generic container|
|`<span>`|Inline container|
|`<ul>`|Unordered list|
|`<li>`|List item|

Example:

```html
<div>

<h2>Products</h2>

<ul>

<li>Keyboard</li>

<li>Mouse</li>

<li>Monitor</li>

</ul>

</div>
```

---

# HTML Attributes

Tags can contain **attributes**.

Example:

```html
<a href="https://example.com">
Visit Website
</a>
```

`href` is an attribute.

Another example:

```html
<img src="logo.png" alt="Logo">
```

Attributes provide additional information.

Common attributes:

|Attribute|Meaning|
|---|---|
|href|Link destination|
|src|Image location|
|class|CSS class|
|id|Unique identifier|
|alt|Alternative image text|

---

# id vs class

These are the two most important attributes in web scraping.

Example:

```html
<h1 id="title">
Linux News
</h1>
```

Another example:

```html
<p class="price">
$499
</p>
```

`id`

- Usually unique.
    
- Appears only once.
    

`class`

- Can appear many times.
    

Example:

```html
<div class="product">
Laptop
</div>

<div class="product">
Keyboard
</div>

<div class="product">
Mouse
</div>
```

Three elements share the same class.

---

# Nested HTML

HTML elements can be inside other elements.

Example:

```html
<div>

<h2>News</h2>

<p>Ubuntu Released</p>

</div>
```

Tree view:

```text
div
├── h2
└── p
```

Real websites often have many levels of nesting.

---

# Inspecting HTML

Save a webpage:

```bash
curl -s https://example.com -o page.html
```

Open it:

```bash
less page.html
```

Search inside `less`:

```
/Example
```

Press **Enter**.

Jump to the next match:

```
n
```

Previous match:

```
Shift + N
```

Quit:

```
q
```

Learning to search HTML quickly is an essential scraping skill.

---

# Finding Links

Suppose a webpage contains:

```html
<a href="/about">About</a>

<a href="/contact">Contact</a>

<a href="/blog">Blog</a>
```

Later, you'll extract all links automatically.

---

# Finding Images

Example:

```html
<img src="logo.png">

<img src="banner.jpg">

<img src="photo.webp">
```

These `src` values can be extracted.

---

# Finding Tables

Tables are commonly used for structured data.

Example:

```html
<table>

<tr>

<td>Rahul</td>

<td>95</td>

</tr>

<tr>

<td>Amit</td>

<td>88</td>

</tr>

</table>
```

This represents:

|Name|Score|
|---|---|
|Rahul|95|
|Amit|88|

---

# Comments in HTML

Example:

```html
<!-- This section is hidden -->
```

Comments are ignored by browsers but still appear in the HTML source downloaded by `curl`.

---

# Whitespace Doesn't Matter

These two examples are equivalent:

```html
<p>Hello</p>
```

```html
<p>

Hello

</p>
```

Browsers ignore extra spaces and line breaks.

---

# Real Website Example

Imagine a product page:

```html
<div class="product">

<h2>Laptop</h2>

<p class="price">$799</p>

<p class="stock">In Stock</p>

</div>
```

From this HTML, you could extract:

- Product name
    
- Price
    
- Stock status

# Browser Developer Tools

One of the easiest ways to inspect HTML is using your browser.

Steps:

1. Open a webpage.
    
2. Right-click on the element.
    
3. Select **Inspect**.
    
4. View the HTML.
    
5. Identify the relevant tag, `id`, or `class`.
    

This helps you understand what you'll later download with `curl`.

---

# Basic Scraping Workflow

```text
Open website
       ↓
Inspect HTML
       ↓
Identify tag/class/id
       ↓
Download HTML using curl
       ↓
Extract data
```

# Common Mistakes

❌ Thinking the browser view is the same as the HTML source.

✔ `curl` retrieves the raw HTML, not the rendered page.

---

❌ Assuming all pages have simple HTML.

✔ Modern websites often have deeply nested HTML and JavaScript-generated content.

---

❌ Looking only for visible text.

✔ Sometimes the information you need is stored in attributes such as `href`, `src`, `id`, or `class`.

---

# Key Takeaways

- HTML is a tree of nested elements.
    
- Tags define different types of content.
    
- Attributes like `id` and `class` help identify elements.
    
- `curl` downloads the raw HTML source.
    
- Browser Developer Tools make it easier to inspect HTML before scraping.
    
- Understanding HTML structure is the foundation for extracting data.
