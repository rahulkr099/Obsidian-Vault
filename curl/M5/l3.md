# Module 5 — Lesson 3: Extracting Data with `grep`

Now that you know how to download HTML using `curl`, it's time to extract useful information from it.

One of the simplest and most powerful Linux tools for this is **`grep`**.

`grep` searches text line by line and prints only the lines that match a pattern.

# What is `grep`?

`grep` stands for **Global Regular Expression Print**.

It searches text files or command output for matching patterns.

Basic syntax:

```bash
grep "pattern" filename
```

Example:

Suppose `names.txt` contains:

```text
Rahul
Amit
Priya
Rahul Kumar
```

Search for Rahul:

```bash
grep "Rahul" names.txt
```

Output:

```text
Rahul
Rahul Kumar
```

---

# Using `grep` with `curl`

Download a webpage and search immediately:

```bash
curl -s https://example.com | grep "Example"
```

Output:

```html
<h1>Example Domain</h1>
```

Instead of viewing the whole HTML page, you only see the matching line.

Search headings:


Search paragraphs:

```bash

```

---

# Case Sensitivity

By default, `grep` is **case-sensitive**.

Example file:

```text
Linux
linux
LINUX
```

Command:

```bash
grep "Linux" file.txt
```

Output:

```text
Linux
```

Ignore case:

```bash
grep -i "linux" file.txt
```

Output:

```text
Linux
linux
LINUX
```

---

# Show Line Numbers

Use `-n`:

```bash
grep -n "<p>" example.html
```

Output:

```text
15:<p>Hello World</p>
```

Useful when inspecting large HTML files.

---

# Count Matches

Use `-c`:

```bash
grep -c "<a" example.html
```

Output:

```text
18
```

Meaning there are 18 links.

---

# Invert the Match

Use `-v`:

File:

```text
apple
banana
orange
```

Command:

```bash
grep -v "banana" fruits.txt
```

Output:

```text
apple
orange
```

Everything except the matching lines is displayed.

---

# Match Whole Words

Without `-w`:

```bash
grep "cat"
```

Matches:

```text
cat
category
scatter
```

With `-w`:

```bash
grep -w "cat"
```

Matches only:

```text
cat
```

---

# Extended Regular Expressions

Use `-E`:

Example:

```bash
grep -E "cat|dog"
```

Matches:

```text
cat
dog
```

This searches for **either** `cat` **or** `dog`.

---

# Recursive Search

Search all HTML files:

```bash
grep -r "<title>" .
```

This searches through the current directory and all subdirectories.

# Find IDs

# Save Matches to a File


# Chain Multiple Commands

Count links on a webpage:

```bash
curl -s https://example.com | grep "<a" | wc -l
```

Workflow:

```text
curl
   ↓
HTML
   ↓
grep
   ↓
Matching lines
   ↓
wc -l
   ↓
Total count
```

# Limitations of `grep`

`grep` works **line by line**.

For example:

```html
<h1>Hello</h1>
```

works well.

But if HTML is written like this:

```html
<h1>
Hello
</h1>
```

Searching with:

```bash
grep "<h1>"
```

only returns:

```html
<h1>
```

The text `Hello` is on a different line, so `grep` alone cannot reconstruct the whole element.

That's why later lessons introduce `sed`, `awk`, and dedicated HTML/XML parsers for more complex extraction.

# Best Practices

- Use `curl -s` to suppress the progress meter when piping to `grep`.
    
- Save the HTML locally if you'll search it multiple times.
    
- Start with simple patterns before using regular expressions.
    
- Remember that `grep` processes one line at a time.
    

---

# Key Takeaways

- `grep` searches text using patterns.
    
- It pairs naturally with `curl` for simple web scraping.
    
- Useful options include `-i`, `-n`, `-c`, `-v`, `-w`, and `-E`.
    
- `grep` is ideal for quick extraction but has limitations with multi-line HTML.
