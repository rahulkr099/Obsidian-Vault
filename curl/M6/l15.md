# Module 6 — Lesson 15: Module Challenge — Secure API Automation ⭐⭐⭐⭐⭐

🎉 **Welcome to the Module 6 Capstone Challenge!**

This challenge combines **everything you've learned** throughout Module 6 into a single real-world project.

Instead of learning one concept at a time, you'll build a complete automation tool similar to what backend engineers, DevOps engineers, and SREs write for production systems.

---

# Mission

Build a Bash application called:

```text
Secure API Automation Client
```

It should be capable of:

- Authenticating with an API
    
- Managing access tokens
    
- Downloading protected files
    
- Verifying file integrity
    
- Logging operations
    
- Handling failures
    
- Using secure secrets
    
- Following security best practices
    

---

# Scenario

Imagine your company exposes an internal API.

Available endpoints:

```text
POST /login

GET /profile

GET /reports

GET /download/latest

POST /logout
```

Your automation script must interact with these endpoints securely.

# Required Features

## Part 1 — Configuration

Load:

```text
API_BASE_URL

USERNAME

PASSWORD

API_KEY

DOWNLOAD_DIR

LOG_FILE

TIMEOUT
```

Everything should come from:

```text
.env
```

Never hardcode secrets.

---

## Part 2 — Login

Workflow:

```text
Start

↓

POST /login

↓

Receive Access Token

↓

Save Token

↓

Continue
```

Expected response:

```json
{
    "accessToken":"...",
    "expiresIn":3600
}
```

Store:

```text
cache/token.json
```

---

## Part 3 — Token Validation

Before every request:

```text
Token Exists?

↓

No

↓

Login

↓

Yes

↓

Expired?

↓

No

↓

Use Token

↓

Yes

↓

Login Again
```

---

## Part 4 — API Calls

Implement:

```text
get_profile()

list_reports()

download_latest()

logout()
```

Each request uses:

```http
Authorization: Bearer TOKEN
```

---

## Part 5 — Download Manager

Requirements:

- HTTPS only
    
- Follow redirects
    
- Resume interrupted downloads
    
- Retry failures
    
- Timeout
    
- Save into:
    

```text
downloads/
```

Recommended `curl` options:

```bash
-L
-C -
--retry
--connect-timeout
--max-time
```

---

## Part 6 — Verify SHA256

After download:

```text
Download

↓

SHA256

↓

Match?

↓

Yes

↓

Success

↓

No

↓

Delete File
```

Use:

```bash
sha256sum
```

---

## Part 7 — Logging

Example:

```text
2026-07-27 09:00 Login successful

2026-07-27 09:01 Fetch profile

2026-07-27 09:03 Download completed

2026-07-27 09:04 SHA256 OK

2026-07-27 09:05 Logout successful
```

Never log:

- Passwords
    
- Tokens
    
- API Keys
    

---

## Part 8 — Error Handling

Handle:

|Status|Action|
|---|---|
|200|Continue|
|301|Follow redirect|
|400|Show error|
|401|Login again|
|403|Permission denied|
|404|Stop|
|429|Retry later|
|500|Retry|
|Timeout|Retry|

---

## Part 9 — Cleanup

Use:

```bash
trap cleanup EXIT
```

Remove:

- Temporary files
    
- Partial downloads
    
- Old logs (if appropriate)
    

---

## Part 10 — Secure Coding

Every script should begin with:

```bash
set -euo pipefail
```

Always:

- Quote variables
    
- Validate JSON
    
- Check return codes
    
- Check file existence
