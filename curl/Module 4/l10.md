# download.sh

Responsibilities

- Accept URL
    
- Resume download
    
- Retry
    
- Progress bar
    
- Save to downloads/
    
- Log result
    

Core command

```bash
curl \
--fail \
-L \
-C - \
--retry 5 \
--retry-all-errors \
--progress-bar \
-O URL
```

---

Workflow

```text
Read URL

↓

Download

↓

Resume

↓

Retry

↓

Save

↓

Log
```

---

# upload.sh

Responsibilities

- PUT upload
    
- Authentication
    
- Retry
    
- Log
    

Core

```bash
curl \
-T FILE \
-H "Authorization: Bearer $TOKEN" \
URL
```

# verify.sh

Responsibilities

# Error Handling

At the top of every script:

```bash
set -euo pipefail
```

Why?

- Stop on errors
    
- Catch undefined variables
    
- Detect pipeline failures
